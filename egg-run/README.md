# 爆速ドラゴニック卵ゲーム🐉（Roblox）

（もとの名前：たまごダッシュ。フォルダ名と保存データの名前は、そのまま残しています）

ルームランナーで足をきたえて、遠くにあるたまごを巣まで持ち帰るゲームです。[Rojo](https://rojo.space/) 形式で作っています。

## 遊び方

1. ベースのルームランナーに乗ると「スピード」が増え、走る速さが上がる（速さ = 16 + スピード ÷ 20、上限 200）
2. 道の先にある5つのゾーンで、たまごを拾う
3. 敵から逃げながら、ベースの巣まで運ぶとコインがもらえる（やられると、たまごを落とす）
4. 届けたたまごは「ふ化の檻」に入り、時間がたつとドラゴンが生まれる
5. コインでショップのアイテムを買い、生まれたドラゴンを連れて強くなる

## ルームランナー

| マシン | スピード/秒 | 使える条件 |
|---|---|---|
| ふつう | +1 | だれでも |
| シルバー | +3 | スピード 100 |
| ゴールド | +8 | スピード 400 |
| ダイヤ | +20 | スピード 1200 |

- 形はジムにある本物に近い：黒いベルト（白い線が後ろへ流れる）、前後のローラー、モーターカバー、2本の柱、操作パネル（画面にマシンの名前・スピード/秒・条件）、手すり、安全キー
- 前（操作パネル側）と横の前半分は手すりがあるので、**後ろ半分の横の ふみ台から乗る**。後ろは低いさくと見えない壁で、ベルトに流されても落ちない
- マシンの色は、横の光る線・操作パネルのふち・手すりの先でわかる
- ベルトの白い線は `src/client/Treadmill.client.luau` が自分の画面の中だけで動かす（通信はふえない）

|---|---|---|---|---|---|---|
| 1 | 草原 | 300 | 1 | 12 | 15 | 15 |
| 2 | 砂漠 | 800 | 2 | 22 | 25 | 40 |
| 3 | 雪原 | 1500 | 3 | 32 | 35 | 100 |
| 4 | 火山 | 2400 | 4 | 46 | 45 | 250 |
| 5 | 雲の上 | 3500 | 5（ボス1体） | 64 | 60 | 600 |
| 6 | 星空 | 4800 | 5 | 78 | 75 | 1500 |

- 星空：足もとは夜空。浮かぶ岩の島と光る結晶、遠くに大きな星。ここに入ると空が夜になる
- 古代の遺跡：ひみつのゾーン。星空の終わりにある門は「やみの竜王を3回たおす」と「図鑑を30種類集める」の両方で開く。開いた人だけが通れる。空は夕方になる
- 敵の頭の上に、名前と体力の数字（例：大トカゲ 18 / 30）が出る。ゲージは緑→黄→赤に変わる

## ショップ

- シューズ：トレーニング効果 2倍 / 3倍 / 5倍 / 10倍
- 体力アップ（175 / 300）、木のたて（ダメージ25%減）、鉄のよろい（ダメージ半分）、ジャンプばね
- 仲間の席（1000コイン：2匹、8000コイン：3匹）：いっしょに連れていけるドラゴンが増える。力は全員分たし合わせ

## ふ化の檻とドラゴン図鑑

- 巣に届けたたまごは、巣の左にある檻に入る（最初は3こまで。ショップの「檻をふやす」で4こ、5こ）
- かえるまでの時間：草原 30秒、砂漠 1分、雪原 2分、火山 4分、雲の上 8分（ゲームを閉じていても進む）
- 時間が来たら、画面左の「🥚 檻」から「かえす！」を押す
- 生まれるのは100種類（属性17 × 体の形6 から2つ抜いたもの）のどれか。遠いたまごほどレアが出やすい

| たまご | ノーマル | レア | スーパーレア | ウルトラレア | レジェンド |
|---|---|---|---|---|---|
| 草原 | 70% | 25% | 5% | 0% | 0% |
| 砂漠 | 50% | 35% | 13% | 2% | 0% |
| 雪原 | 30% | 38% | 24% | 7% | 1% |
| 火山 | 15% | 30% | 33% | 18% | 4% |
| 雲の上 | 5% | 20% | 35% | 28% | 12% |

- 体の形で得意なことが決まり、レア度が高いほど強い（ドラ＝トレーニング、ウイング＝速さ、ガイア＝ダメージ減、フェニックス＝回復、トリプル＝コイン、ザウルス＝こうげき）
- レアなほど強そうな見た目になり、体も大きくなる（レジェンドはノーマルの1.4倍）
  - ★2 レア：銀の角が1組ふえ、背中のとげがふえる
  - ★3 スーパーレア：角が2組、目が光る、とげが金属に、胸に宝石
  - ★4 ウルトラレア：金の角が3組（かんむり）、とげと体のもようが光る、キラキラと光をまとう
  - ★5 レジェンド：頭の上に光の輪、光の粒が舞う
  - はじめの仲間にはレア度がないので、この飾りはつかない
- 画面左の「📖 図鑑」で、100種類をカードで見られる。まだ仲間にしていないドラゴンは黒い影で、名前は「？？？」。カードをタップすると、くわしい説明（まだのドラゴンは、どこのたまごから生まれるか）が出る

## 防具（「🛡️ 防具」タブ）

5つの場所 × 2種類 × 5つのレア度 ＝ 50個（`Config.Armors`、A01〜A50）。場所ごとに1つずつ身につけられ、つけるとキャラの見た目が変わる。

| 場所 | 防具 | 上がる力（★1 → ★5） |
|---|---|---|
| 頭 | かぶと | 受けるダメージ -6% → -22% |
| 頭 | とんがりぼうし | トレーニング +20% → +100% |
| 体 | よろい | 体力 +50 → +900 |
| 体 | ローブ | 回復 毎秒 +2 → +16 |
| うで | こて | 武器のこうげき力 +10% → +80% |
| うで | うでわ | たまごのコイン +10% → +50% |
| 足 | ブーツ | 走る速さ +2 → +10 |
| 足 | すねあて | 受けるダメージ -6% → -22% |
| せなか | マント | 体力 +30 → +600 |
| せなか | つばさ | ジャンプ力 +6 → +30 |

- レア度は材料で決まる：★1 かわ、★2 てつ、★3 ミスリル、★4 黄金竜、★5 星くず。ねだんの基本は 200 / 2,000 / 15,000 / 100,000 / 500,000 コイン（種類で少しちがう）
- どの防具にも、レア度に応じた体力（+10 / 25 / 50 / 100 / 200）がつく
- 受けるダメージをへらす力は、合わせて 60% まで（`Config.ArmorDefenseCap`）
- 見た目：レア度が上がると飾りがふえる（★2 ふち、★3 宝石、★4 角やとげ、★5 キラキラ）。R15 でも R6 でも体の大きさに合わせてつく（`src/server/Armor.luau`）
- ためし用の無料中（`Config.FreeWeaponsForTest = true`）は、防具も無料

## ドラゴンを育てる

- **レベル**：連れているドラゴンは、敵をたおす・たまごを届ける・ルームランナーで走ると経験値が入る（最大 Lv30）。1レベルごとにこうげき力 5% アップ
- **わざ**：Lv5 で覚える。右の「✨ わざ」ボタンで、連れているドラゴン全員が使う（25秒に1回）

| 体の形 | わざ |
|---|---|
| ドラ（ちびドラゴン） | がんばれコール：15秒 トレーニング 3倍 |
| ウイング（いかずちドラゴン） | おいかぜ：8秒 走る速さ +40 |
| シルバーウイング | 海風のまもり：8秒 走る速さ +30 |
| ガイア | マグマバリア：6秒 ダメージを受けない |
| フェニックス | いやしの炎：体力 60% 回復 |
| トリプル | トリプルブレス：まわりの敵に こうげき力×6 |
| ザウルス | だいじしん：まわりの敵を4秒止めて ×3 |
| ディープブルー | だいつなみ：まわりの敵を3秒止めて ×3 |

- **進化**：同じドラゴンが3体いると、ひとつ上のレア度のドラゴン（できれば同じ体の形）に進化。経験値は引きつぐ
- **交配**：「🥚 檻」タブで親を2匹えらぶ。片方の「体の形」ともう片方の「属性」を合わせた子どものたまごが檻に入る（親はいなくならない。コインがいる）
- **卒業**：いらないドラゴンを手放してコインにする（★1 30 〜 ★5 6000）。図鑑には残る

## 何度でも遊べるしくみ

右上のステータスの下の帯に、いまのボーナスが順番に出る。帯を押すと、くわしい画面と転生のボタンが開く（`src/client/Adventure.client.luau`）。

- **転生**：スピードが 3,000 にとどくと転生できる（2回目からは 1.4倍ずつ多くいる：4,200 → 5,900 → 8,200 …）。スピードとコインは 0 にもどるが、ドラゴン・武器・防具・ショップの商品・図鑑・実績はのこる。1回ごとに トレーニング +50%・たまごのコイン +25% がずっと続き、おいわいに ふしぎなたまごが 1こ かえる。回数で よび名がつく（ルーキー → ベテラン → たつじん → マスター → でんせつ → 神話）
- **れんぞく配達**：やられずに続けて届けるたびに コイン +10%（+100% まで）。やられると 0 にもどる
- **タイムアタック**：たまごを拾ってから届けるまでの時間をはかる。ゾーンごとの自分の記録をぬりかえると、たまご 1こ分のコインがおまけ。運んでいる間は 帯にタイムが出る
- **あたりゾーン**：10分ごとに入れかわる（全部のサーバーで同じ）。そのゾーンのたまごは コイン 3倍
- **宝箱**：45秒ごとに 道のどこかに出る（4こまで、4分で消える）。さわると その場所のごほうびの 2〜6倍のコイン。12% で ふしぎなたまご、4% で大当たり（25倍）
- **天気**：5分ごとに変わる（全部のサーバーで同じ）

| 天気 | 出やすさ | 力 |
|---|---|---|
| ☀️ はれ | 30 | なし |
| 🌧️ あめ | 20 | トレーニング 1.5倍 |
| 🍃 おいかぜ | 16 | 走る速さ +8 |
| 🌫️ きり | 14 | 敵のコイン 2倍 |
| ⛈️ かみなり | 12 | ドラゴンの経験値 2倍 |
| 🌈 にじ | 8 | たまごのコイン 1.5倍 |

数字は `Config.Rebirth` / `Combo` / `TimeAttack` / `Lucky` / `Weathers` / `Chest` で変えられる。

## 見た目（本物らしさ）

- **空**（`src/client/Ambience.client.luau`）：20分で 1日がまわる（朝やけ → 昼 → 夕やけ → 夜。夜は月明かり）。天気で 雲の量・明るさ・かすみが変わり、雨・ふぶき・風に流れる葉・かみなりの光・空にかかる にじ が出る。星空はいつも夜、遺跡はいつも夕方、塔はむらさきの夜
- **場所の空気**：草原は花粉（夜は ほたる）、砂漠は黄色いかすみと砂ぼこり、雪原は青白い空気と雪、火山は赤黒い空気と火の粉・灰、星空は星くず
- **武器**：刃はまん中が厚く 両がわがうすい形で、みぞが 1本通り、先は三角にとがる。金属はまわりをうつし、影を落とす。にぎりは革を巻き、柄には金具の輪。斧は とがれた刃先と びょう
- **防具**：かぶとは丸い鉢・ほおあて・びょう。よろいは 胸のふくらみ・おなかの かさね板・丸い かた当て。マント・ローブ・ぼうしは布の手ざわりで、マントは 4枚つなぎで下へ広がる。つばさは 羽を 3枚かさねて じく（まん中の線）をつけた
- **敵とドラゴン**（`Rig.luau` / `Anatomy.luau` / `Enemies.luau`）：せなかは こく おなかは 明るい 自然な色の流れと、部品ごとの わずかな色むら。目は ぬれて光をうつし、虹彩の輪と たてに細い ひとみ。首としっぽの下には 明るい はら板。足には 太ももの筋肉・ひざの関節・指・先の黒い つめ・かかとの つめ。つばさの膜は 光が少しすけ、すじ（血管）と 指の関節・つめがつく。敵は 歯がならび（前の きばが長い）、下の歯と舌があり、せなかに ワニのような 皮の こぶ（オオカミは さか立つ毛）
- 材料の手ざわりは Roblox の新しい材料（`MaterialService.Use2022Materials`）を使う
- 絵や 3D の形のデータ（メッシュ・テクスチャ）は使っていない。全部 Roblox の部品と材料で作っている

## 画面（メニュー）

- 左のメニュー：絵のついた四角いボタンが 2列（ショップ・武器・防具・仲間・図鑑・檻・毎日・ベースへ）。受け取れるものがあると、右上に赤い丸が出る
- ショップの窓：タブは 4つ × 2段で、タブごとに色がちがう。えらんだタブだけ明るく白いふちがつく。開くときに ぽんっと大きくなる
- ボタンは押すと へこんで はねてもどり、音が鳴る
- ログインボーナスの画面：7日分のカードがならぶカレンダー。今日のカードは金色で はずむ。「受け取る！」で はんこが押され、コインが右上へ飛んでいく。入ったときに、まだもらっていなければ自動で開く

## 毎日のごほうび（画面左「🎁 毎日」）

- **ログインボーナス**：7日でひとまわり。7日目は「ふしぎなたまご」つき。1日休むと1日目から。日付は日本時間で変わる
- **今日のミッション**：毎日3つ（たまごを届ける・敵をたおす・たまごをかえす・スピードをきたえる・一番遠いゾーンのたまご・塔の階）。3つ全部でふしぎなたまご
- **無料のたまご**：4時間に1回、その場でかえる
- ふしぎなたまごは、行ったことのある一番遠いゾーン（雲の上まで）のたまごと同じ出やすさ
- コインの量は、遠くまで行けるようになるほど増える
- **黄金のたまごイベント**：毎時0分と30分から3分間、道のどこかに光の柱と黄金のたまごが出る。運ぶと800コインと、レアが出やすいたまご（★3以上が9割）

## 実績（「🏆 実績」タブ）

たまご運び・ふ化・敵・ボス・トレーニング・図鑑・塔・ログイン・進化・交配・卒業・レベルなど。達成するとコインがもらえる。
図鑑のコンプリートボーナスもここ（10種類 500 / 25種類 2000 / 50種類 8000 / 75種類 20000 / 100種類 100000）。

## 塔のぼり

ベースの左うしろの塔に入ると、空の上の部屋へワープ。敵を全部たおすと次の階へ（5階ごとにボス）。
階をクリアするたびにコイン。やられるか「🏠 ベースへ」で出る。部屋はプレイヤーごとに作られる。

## はじめの仲間（全員無料。連れていける）

画面左の「🐉 ドラゴン」から選びます。近くの敵を自動でこうげきし、たおすとコインがもらえます。敵は少したつと復活します（ボスは30秒、ほかは12秒）。

## 風景（src/server/Scenery.luau）

- 道の外は Roblox の地形（Terrain）で作る。草原は丘・池・森、砂漠は砂丘と岩の台地、雪原は雪山とこおった湖、火山は溶岩の川とけむりを上げる火山、雲の上は雲の海
- 道とベースの地面は平らなまま。見た目は地形にまかせ、歩く床は見えない部品（y = 0）にしている（敵の動きを変えないため）
- 道の中の木・サボテン・岩も、ここで作る（地形を作ったあとに置く）
- 地形のはしと、雲の上のゾーンの道の外には、見えない壁がある
- 道から遠い木は影を落とさない（軽くするため）
