# 爆速ドラゴニック卵ゲーム🐉（Roblox）

（もとの名前：たまごダッシュ。フォルダ名と保存データの名前は、そのまま残しています）

ルームランナーで足をきたえて、遠くにあるたまごを巣まで持ち帰るゲームです。[Rojo](https://rojo.space/) 形式で作っています。

## 遊び方

1. ベースのルームランナーに乗ると「スピード」が増え、走る速さが上がる（速さ = 16 + スピード ÷ 20、上限 200）
2. 道の先にある5つのゾーンで、たまごを拾う
3. 敵から逃げながら、ベースの巣まで運ぶとコインがもらえる（やられると、たまごを落とす）
4. 届けたたまごは「ふ化の檻」に入り、時間がたつとドラゴンが生まれる
5. コインでショップのアイテムを買い、生まれたドラゴンを連れて強くなる

## ショップ

- シューズ：トレーニング効果 2倍 / 3倍 / 5倍 / 10倍
- 体力アップ（175 / 300）、木のたて（ダメージ25%減）、鉄のよろい（ダメージ半分）、ジャンプばね

## ふ化の檻とドラゴン図鑑

- 巣に届けたたまごは、巣の左にある檻に入る（最初は3こまで。ショップの「檻をふやす」で4こ、5こ）
- かえるまでの時間：草原 30秒、砂漠 1分、雪原 2分、火山 4分、雲の上 8分（ゲームを閉じていても進む）
- 時間が来たら、画面左の「🥚 檻」から「かえす！」を押す
- 生まれるのは100種類（属性17 × 体の形6 から2つ抜いたもの）のどれか。遠いたまごほどレアが出やすい

| たまご | ノーマル | レア | スーパーレア | ウルトラレア | レジェンド |
|---|---|---|---|---|---|
| 草原 | 70% | 25% | 5% | 0% | 0% |
| 砂漠 | 50% | 35% | 13% | 2% | 0% |
| 雪原 | 30% | 38% | 24% | 7% | 1% |
| 火山 | 15% | 30% | 33% | 18% | 4% |
| 雲の上 | 5% | 20% | 35% | 28% | 12% |

- 体の形で得意なことが決まり、レア度が高いほど強い（ドラ＝トレーニング、ウイング＝速さ、ガイア＝ダメージ減、フェニックス＝回復、トリプル＝コイン、ザウルス＝こうげき）
- レアなほど強そうな見た目になり、体も大きくなる（レジェンドはノーマルの1.4倍）
  - ★2 レア：銀の角が1組ふえ、背中のとげがふえる
  - ★3 スーパーレア：角が2組、目が光る、とげが金属に、胸に宝石
  - ★4 ウルトラレア：金の角が3組（かんむり）、とげと体のもようが光る、キラキラと光をまとう
  - ★5 レジェンド：頭の上に光の輪、光の粒が舞う
  - はじめの仲間にはレア度がないので、この飾りはつかない
- 画面左の「📖 図鑑」で、100種類をカードで見られる。まだ仲間にしていないドラゴンは黒い影で、名前は「？？？」。カードをタップすると、くわしい説明（まだのドラゴンは、どこのたまごから生まれるか）が出る

## はじめの仲間（全員無料。1体えらんで連れていける）

画面左の「🐉 ドラゴン」から選びます。近くの敵を自動でこうげきし、たおすとコインがもらえます。敵は少したつと復活します（ボスは30秒、ほかは12秒）。

| ドラゴン | 力 | こうげき（威力×数 / 間かく / 届く距離） |
|---|---|---|
| ちびドラゴン | トレーニング 1.5倍 | 8 / 1秒 / 35 |
| いかずちドラゴン | 走る速さ +10 | 12 / 0.5秒 / 45 |
| ガイアマグマ（大地とマグマ） | ダメージ 40% ダウン | 35 / 1.3秒 / 40 |
| シルバーウイング（海と風の守り神） | 走る速さ +15・体力が 1秒に 2 回復 | 25 / 0.8秒 / 50 |
| ディープブルー（海の巨大ドラゴン） | ダメージ 30% ダウン・コイン 1.2倍 | 40 / 1.2秒 / 45 |
| トリプルヘッド（三つ首） | たまごのコイン 1.5倍 | 15×3 / 1.2秒 / 45 |
| ギガザウルス（怪獣） | こうげき力 最強 | 70 / 1.4秒 / 55 |
| フェニックス（炎の不死鳥） | 体力が 1秒に 5 回復 | 20 / 0.9秒 / 50 |

敵の体力：草原 30、砂漠 90、雪原 220、火山 500、雲の上 1000（ボスは 4倍）

敵の見た目：草原＝大トカゲ、砂漠＝大サソリ、雪原＝氷のオオカミ、火山＝溶岩サンショウウオ、雲の上＝あらしの竜。雲の上のボスは「やみの竜王」。

数字はすべて `src/shared/Config.luau` で変えられます。

## ファイル構成

```

```

## ビルドとアップロード

```sh
cd egg-run
mkdir -p build
rojo build -o build/EggDash.rbxl
curl -X POST \
  "https://apis.roblox.com/universes/v1/<UNIVERSE_ID>/places/<PLACE_ID>/versions?versionType=Published" \
  -H "x-api-key: <API_KEY>" \
  -H "Content-Type: application/octet-stream" \
  --data-binary @build/EggDash.rbxl
```

## 風景（src/server/Scenery.luau）

- 道の外は Roblox の地形（Terrain）で作る。草原は丘・池・森、砂漠は砂丘と岩の台地、雪原は雪山とこおった湖、火山は溶岩の川とけむりを上げる火山、雲の上は雲の海
- 道とベースの地面は平らなまま。見た目は地形にまかせ、歩く床は見えない部品（y = 0）にしている（敵の動きを変えないため）
- 道の中の木・サボテン・岩も、ここで作る（地形を作ったあとに置く）
- 地形のはしと、雲の上のゾーンの道の外には、見えない壁がある
- 道から遠い木は影を落とさない（軽くするため）
