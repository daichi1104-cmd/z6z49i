# たまごダッシュ（Roblox）

ルームランナーで足をきたえて、遠くにあるたまごを巣まで持ち帰るゲームです。[Rojo](https://rojo.space/) 形式で作っています。

## 遊び方

1. ベースのルームランナーに乗ると「スピード」が増え、走る速さが上がる（速さ = 16 + スピード ÷ 20、上限 200）
2. 道の先にある5つのゾーンで、たまごを拾う
3. 敵から逃げながら、ベースの巣まで運ぶとコインがもらえる（やられると、たまごを落とす）
4. コインでショップのアイテムやドラゴンの仲間を買って強くなる

## ルームランナー

| マシン | スピード/秒 | 使える条件 |
|---|---|---|
| ふつう | +1 | だれでも |
| シルバー | +3 | スピード 100 |
| ゴールド | +8 | スピード 400 |
| ダイヤ | +20 | スピード 1200 |

## ゾーン（遠いほどむずかしい）

| # | ゾーン | 距離 | 敵の数 | 敵の速さ | ダメージ | ごほうび |
|---|---|---|---|---|---|---|
| 1 | 草原 | 300 | 1 | 12 | 15 | 15 |
| 2 | 砂漠 | 800 | 2 | 22 | 25 | 40 |
| 3 | 雪原 | 1500 | 3 | 32 | 35 | 100 |
| 4 | 火山 | 2400 | 4 | 46 | 45 | 250 |
| 5 | 雲の上 | 3500 | 5（ボス1体） | 64 | 60 | 600 |

## ショップ

- シューズ：トレーニング効果 2倍 / 3倍 / 5倍 / 10倍
- 体力アップ（175 / 300）、木のたて（ダメージ25%減）、鉄のよろい（ダメージ半分）、ジャンプばね

## ドラゴンの仲間（1体つれていける）

近くの敵を自動でこうげきします。敵をたおすとコインがもらえ、敵は少したつと復活します（ボスは30秒、ほかは12秒）。

| ドラゴン | 値段 | 力 | こうげき（威力×数 / 間かく / 届く距離） |
|---|---|---|---|
| ちびドラゴン | 最初から | トレーニング 1.2倍 | 8 / 1秒 / 35 |
| いかずちドラゴン | 250 | 走る速さ +8 | 15 / 0.7秒 / 45 |
| ガイアマグマ | 800 | ダメージ 30% ダウン | 40 / 1.5秒 / 40 |
| トリプルヘッド（三つ首） | 2000 | たまごのコイン 2倍 | 20×3 / 1.2秒 / 45 |
| ギガザウルス（怪獣） | 5000 | トレーニング 2倍＋速さ +15 | 90 / 1.6秒 / 55 |

敵の体力：草原 30、砂漠 90、雪原 220、火山 500、雲の上 1000（ボスは 4倍）

数字はすべて `src/shared/Config.luau` で変えられます。

## ファイル構成

```
default.project.json            Rojo のプロジェクト設定
src/shared/Config.luau          バランスの数字（マシン・ゾーン・商品・ドラゴン）
src/server/WorldBuilder.luau    マップの組み立て（ベース・ルームランナー・ショップ・巣・道）
src/server/Enemies.luau         たまごを守る敵の動き
src/server/Dragons.luau         ドラゴンの模型と、ついて来る動き
src/server/Main.server.luau     保存・トレーニング・たまご回収・購入
src/client/HUD.client.luau      画面表示（ステータス・ショップ・お知らせ）
```

## ビルドとアップロード

```sh
cd egg-run
mkdir -p build
rojo build -o build/EggDash.rbxl
curl -X POST \
  "https://apis.roblox.com/universes/v1/<UNIVERSE_ID>/places/<PLACE_ID>/versions?versionType=Published" \
  -H "x-api-key: <API_KEY>" \
  -H "Content-Type: application/octet-stream" \
  --data-binary @build/EggDash.rbxl
```
