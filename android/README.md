# 録画・録音（Android アプリ）

スマホの画面に映っている映像と、アプリから出ている音（YouTube など）を記録する Android アプリです。

- 録画（映像＋音声、MP4）と、録音（音声のみ、M4A）を切り替えられます
- 画面の向き（横向き / 縦向き）と画質（1080p / 720p）を選べます
- 開始すると YouTube アプリを自動で開けます
- 通知の「停止」ボタンで、YouTube を見たまま止められます
- 録画は `Movies/ScreenRecorder`、録音は `Music/ScreenRecorder` に保存され、ギャラリーやファイルアプリから見られます
- マイクの音は録音しません（アプリから出ている音だけを録音します）

## 対応機種

Android 10 以降。他のアプリの音を録音する仕組みが Android 10 からしかないためです。iPhone には対応していません。

## APK の入手とインストール

1. GitHub のリポジトリの「Actions」タブで「Android APK」の最新の実行を開く
2. 下の「Artifacts」から `ScreenRecorder-apk` をダウンロードし、ZIP を展開して `app-debug.apk` を取り出す
3. APK をスマホに送り、開いてインストールする（「提供元不明のアプリ」を許可するよう求められたら許可する）

## 使い方

1. 「録画開始」または「録音開始」を押す
2. 初回は「マイク」と「通知」の許可を求められるので許可する（マイクはアプリの音を録音するために必要なだけで、マイクの音は録音しません）
3. 確認画面で「開始」を押す。Android 14 以降は「1つのアプリ」で YouTube を選ぶと、通知などが映り込みません
4. YouTube で動画を再生する
5. 通知の「停止」を押すか、アプリに戻って「停止して保存」を押す

## うまくいかないとき

- **音が入らない**：再生しているアプリが「録音されないように」設定していると無音になります。保存後に「音が入っていません」と表示されたら、Chrome で YouTube（m.youtube.com）を開いて再生してみてください
- **画面が黒い**：DRM で保護された動画や、録画を禁止しているアプリは黒く映ります

## 自分でビルドする

Android Studio でこの `android` フォルダを開いて実行するか、次のコマンドで APK を作れます。

```bash
cd android
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk ができる
```
