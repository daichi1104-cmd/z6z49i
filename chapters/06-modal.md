# 第6章　モード・ジャズ

## 6.1　コードが変わらない音楽で、何を弾くか

1950年代の終わりから、ジャズには**モード・ジャズ**と呼ばれるスタイルが現れました。それまでのジャズが、Ⅱ-Ⅴ-Ⅰのような細かいコード進行の上で演奏されていたのに対し、モード・ジャズでは1つのコード（1つのモード）が8小節、16小節と長く続きます。

ベーシストにとって、これは大きな変化です。第3章までのウォーキングは、「次のコードの1拍目へ近づく」ことでラインに推進力を生んでいました。コードが変わらなければ、近づく先がありません。モード・ジャズのベーシストは、**コードの変化に頼らずに、ラインそのものの形で音楽を前に進める**必要があります。

この章では、そのための方法を4つ取り上げます。

1. モードの**特性音**を聞かせる
2. **ペダル・ポイント**とヴァンプで、上声部の和音と組み合わせる
3. モードが切り替わる瞬間を、ベースで示す
4. **4度の音程**でラインを作る

## 6.2　モードの特性音

同じ D から始まるモードでも、音の並びが1音違うだけで響きは大きく変わります。それぞれのモードを、ほかのモードと区別する音を**特性音**と呼びます。

| モード | 音（D から） | 特性音 | 響きの特徴 |
|---|---|---|---|
| ドリアン | D E F G A B C | B（長6度） | 短調だが明るさがある。モード・ジャズで最もよく使われる |
| フリジアン | D E♭ F G A B♭ C | E♭（短2度） | スペイン風の暗い響き |
| リディアン | D E F♯ G♯ A B C♯ | G♯（増4度） | 浮遊感のある明るい響き |
| ミクソリディアン | D E F♯ G A B C | C（短7度） | ブルージーな長調 |
| エオリアン | D E F G A B♭ C | B♭（短6度） | 自然な短調 |

ベースラインでモードを示すには、**特性音を強拍や長い音符に置く**のが効果的です。たとえば Dm7 が8小節続く場面で、ベースが B を強調すればドリアン、B♭ を強調すればエオリアンとして聞こえます。ピアニストやソリストと同じモードを共有するために、ベーシストは特性音を意識して弾く必要があります。

## 6.3　1つのモードの上でウォーキングする

モードの上でウォーキングするときは、第3章までとは違う注意が必要です。

- **特性音を聞かせる。** D ドリアンなら B を、強拍や小節の頭近くに置く。
- **調性的な解決を避ける。** D ドリアンの上で C♯ を弾いたり、A → D の5度の動きを強拍で繰り返したりすると、A7 → Dm の「ドミナント → トニック」に聞こえて、モードの浮遊感が失われる。
- **毎小節ルートから始めない。** 8小節を1つの単位として、ラインの山と着地を設計する（第3章の 3.4節）。

譜例6-1は、D ドリアンの上で8小節のウォーキングを弾いた例です。すべて第2章の Dポジション（⑥弦の D1 に人差し指を置いた手の位置）で弾けます。

```lilypond {#ex6-1 caption="譜例6-1　Dドリアンの上でのウォーキング（8小節）"}
<<
  \new ChordNames \chordmode { d1:m7 d:m7 d:m7 d:m7 d:m7 d:m7 d:m7 d:m7 }
  \new Staff {
    \clef bass \time 4/4
    d4\4 e\4 f\3 g\3 | a\3 b\2 c'\2 b\2 |
    d'4\2 c'\2 a\3 b\2 | e'\1 d'\2 b\2 g\3 | \break
    a4\3 f\3 e\4 d\4 | c\4 a,\5 g,\5 e,\6 |
    d,4\6 f,\6 a,\5 b,\5 | c\4 a,\5 b,\5 c\4 \bar "||"
  }
>>
```

ラインの設計を確かめてみます。

- **特性音 B**：2小節目の2拍目と4拍目、3小節目の4拍目、4小節目の3拍目、7小節目の4拍目、8小節目の3拍目に置いています。8小節の中で何度も B が聞こえることで、ドリアンの響きがはっきりします。
- **形**：1〜4小節目で D2 から上がって4小節目の E3 を頂上にし、5〜7小節目で下りて、7小節目の頭で D1 に着地します。
- **避けた音**：C♯ は一度も使っていません。8小節目の最後の C2 は、次の D2 へ全音下から戻る音です。半音下の C♯ を使うと、ここで調性的な解決に聞こえてしまいます。

## 6.4　ペダル・ポイントとヴァンプ

**ペダル・ポイント**は、ベースが同じ音を弾き続け、その上で和音が動く書法です。**ヴァンプ**は、短いリズム・パターンを繰り返して、ソリストの土台を作る伴奏です。モード・ジャズのイントロやソロの伴奏では、この2つがよく使われます。

6弦ベースなら、ペダルのルートと、上声部の4度の和音（第5章の 5.3節）を1人で組み合わせられます。譜例6-2は、⑤弦の D2 をペダルにして、③②①弦の4度の和音を答えさせるヴァンプです。

```lilypond {#ex6-2 caption="譜例6-2　ペダル・ポイントと4度の和音のヴァンプ"}
<<
  \new ChordNames \chordmode { d1:m7 d:m7 }
  \new PianoStaff <<
    \new Staff {
      \clef treble \time 4/4 \set stringNumberOrientations = #'(up)
      \repeat volta 2 {
        r2 <a\3 d'\2 g'\1>4 <b\3 e'\2 a'\1>4 |
        r2 <d'\3 g'\2 c''\1>4 <b\3 e'\2 a'\1>4
      }
    }
    \new Staff {
      \clef bass \time 4/4 \set stringNumberOrientations = #'(down)
      \repeat volta 2 {
        d4.\5 d8\5 r2 | d4.\5 d8\5 r2
      }
    }
  >>
>>
```

前半の2拍でルートの D をリズムよく弾き、後半の2拍で和音を答えさせています。ベースと伴奏の役割を、拍で分けている形です。

ヴァンプを弾くときは、次の点に気をつけてください。

- **パターンを変えすぎない。** ヴァンプの役割は、ソリストが安心して乗れる土台を作ることです。同じパターンを繰り返すほど、ソリストは自由に演奏できます。
- **変化は大きな単位で付ける。** 8小節や16小節ごとに、和音の位置やリズムを少しだけ変えます。
- **ソロが盛り上がったら、ペダルを外す。** ソリストが山場に来たところで、ペダルからウォーキングに切り替えると、バンド全体のエネルギーが一段上がります。

## 6.5　モードが切り替わる瞬間

モード・ジャズの曲でも、セクションごとにモードが変わることがあります。たとえば、D ドリアンが16小節続いたあと、半音上の E♭ ドリアンに8小節移る、という形式です。

モードの切り替わりは、コードの変化が少ない曲の中で数少ない「事件」です。ベーシストは、**切り替わりの直前でラインを新しいモードへ導き、切り替わった瞬間に新しいモードの特性音を聞かせる**ことで、この事件をはっきり示します。

```lilypond {#ex6-3 caption="譜例6-3　Dドリアンから E♭ドリアンへの切り替わり"}
<<
  \new ChordNames \chordmode { d1:m7 d:m7 es:m7 es:m7 }
  \new Staff {
    \clef bass \time 4/4
    d4\4 f\3 a\3 b\2 | c'\2 a\3 f\3 e\4 |
    es4\4 ges\3 bes\2 c'\2 | des'\2 bes\2 ges\3 es\4 \bar "||"
  }
>>
```

- **1〜2小節目（D ドリアン）**：1小節目の4拍目で特性音の B を聞かせます。2小節目では下行して、4拍目の E2 から E♭2 へ半音上から近づきます。
- **3〜4小節目（E♭ ドリアン）**：E♭ ドリアンの特性音は C（長6度）です。3小節目では E♭m7 のコード・トーンを上がって、4拍目にその C3 を置いています。
- 4小節目の最後の E♭2 は、最初の D2 に半音上から戻る音です。

E♭ ドリアンに移っても、手の位置は Dポジションのままです。押さえる音の組み合わせだけが、半音ずつずれます。

## 6.6　4度の音程でラインを作る

モード・ジャズのピアニストやサックス奏者は、**4度の音程を積み重ねたフレーズ**をよく使います。3度を積んだアルペジオがはっきりしたコードの響きを作るのに対し、4度を積んだフレーズは、調性のはっきりしない開かれた響きを作るからです。

ベースの弦は、隣り合う弦がすべて完全4度の関係にあります。そのため、**1本の指で複数の弦をまとめて押さえ、そのまま弦を順に弾くだけで、4度のフレーズになります**。ほかの楽器では難しいこの種のフレーズが、ベースでは最も弾きやすい形になります。

譜例6-4は、D ドリアンの上で、⑤弦から①弦まで同じ指の形のまま4度を上下し、2小節目で形を少し高い位置にずらした例です。

```lilypond {#ex6-4 caption="譜例6-4　4度の音程によるフレーズ（Dドリアン）"}
<<
  \new ChordNames \chordmode { d1:m7 d:m7 d:m7 }
  \new Staff {
    \clef bass \time 4/4
    a,8\5 d\4 g\3 c'\2 f'\1 c'\2 g\3 d\4 |
    b,8\5 e\4 a\3 d'\2 g'\1 d'\2 a\3 e\4 |
    d1\4 \bar "||"
  }
>>
```

1小節目の音（A - D - G - C - F）は、D ドリアンの上では 5度、1度、11度、7度、3度になります。2小節目の音（B - E - A - D - G）は、13度、9度、5度、1度、11度です。2小節目では、特性音の B から始まっていることに注目してください。どちらの形も、すべて Dポジションの中で弾けます。

このフレーズはウォーキングではなく、ソロや、ソリストへの合いの手（フィル）で使う語法です。第7章のソロの語法で、さらに広げます。

## 6.7　練習課題

1. 6.2節の表のモードを、すべて D から Dポジションで2オクターブずつ弾いてください。特性音を弾くときだけ、少し長く伸ばします。
2. 譜例6-1と同じく D ドリアンで8小節のウォーキングを作ってください。特性音の B を強拍に3回以上置き、C♯ は使いません。
3. 譜例6-2のヴァンプを8回繰り返し、5回目から上声部の和音の位置を変えてください。ルートのリズムは変えません。
4. D ドリアン16小節 → E♭ ドリアン8小節 → D ドリアン8小節の32小節の形式で、1コーラスのラインを作ってください。切り替わりの前後2小節は、譜例6-3を参考にします。
5. 譜例6-4の4度のフレーズを、E♭ ドリアンの上で作ってください。E♭ ドリアンの音だけになる指の形の位置を探します。

## 6.8　まとめ

- モード・ジャズでは、コードの変化に頼らず、ラインの形で音楽を前に進める。
- モードは特性音で区別される。ベースは特性音を強拍や長い音符に置いて、モードを示す。
- ドリアンの上では、導音（C♯）や強拍での A → D の動きを避け、調性的な解決を感じさせない。
- ペダル・ポイントとヴァンプでは、ルートと4度の和音を拍で分けて弾く。パターンは変えすぎない。
- モードの切り替わりでは、直前にラインを新しいモードへ導き、新しいモードの特性音を聞かせる。
- 隣り合う弦が4度の関係にあるので、同じ指の形のまま弦を順に弾くと4度のフレーズになる。
