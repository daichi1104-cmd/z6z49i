# 第9章　練習曲

この章には、第1章から第8章までの内容をまとめた8つの練習曲を収めました。どの曲も本書のために作ったオリジナルです。

練習曲は、次の順番で取り組むと効果的です。

1. **ゆっくり弾く。** メトロノームを遅めに設定し、譜面の弦の指定どおりに弾きます。
2. **ポイントを確かめる。** 各曲の「ポイント」を読み、その曲で何を練習しているのかを意識しながら弾きます。
3. **テンポを上げる。** 弦の指定どおりに弾けるようになったら、少しずつテンポを上げます。
4. **自分のラインに変える。** 同じコード進行で、ポイントの考え方を守りながら、自分のラインを作ります。練習曲は、そのための手本です。

ほとんどの曲は、第2章の Dポジション（⑥弦の D1 に人差し指を置いた手の位置）の中で弾けるように作ってあります。手の位置を変える場所は、各曲のポイントに書いてあります。

## 練習曲1　三つの音域

**関連する章**：第1章・第3章

F のブルース12小節のウォーキングです。1〜4小節目で中域から高域へ上がり、5〜8小節目は高域にとどまり、9小節目から下りて、最後の2小節で初めて Low B 弦の音域（E♭1、D1、C1）を使います。

```lilypond {#et1 caption="練習曲1　三つの音域"}
<<
  \new ChordNames \chordmode { f1:7 bes:7 f:7 f:7 bes:7 bes:7 f:7 d:7 g:m7 c:7 f:7 c:7 }
  \new Staff {
    \clef bass \time 4/4
    f,4\6 a,4\5 c4\4 b,4\5 |
    bes,4\5 d4\4 f4\3 ges4\3 |
    f4\3 a4\3 c'4\2 d'4\2 |
    ees'4\1 d'4\2 c'4\2 a4\3 | \break
    bes4\2 d'4\2 f'4\1 d'4\2 |
    aes4\3 bes4\2 c'4\2 e'4\1 |
    f'4\1 ees'4\1 c'4\2 a4\3 |
    d'4\2 c'4\2 a4\3 fis4\3 | \break
    g4\3 f4\3 d4\4 bes,4\5 |
    c4\4 bes,4\5 g,4\5 e,4\6 |
    f,4\5 ees,4\6 d,4\6 c,4\6 |
    c,2\6 e,4\6 g,4\5 \bar "|."
  }
>>
```

**ポイント**

- 5〜7小節目で①弦の F3 を頂上にし、そこから11小節目まで一度も上に戻らずに下ります（第3章 3.4節）。
- Low B 弦の音域は11〜12小節目だけです。曲の最後の山場のためにとっておく、という第3章の考え方を実際に試します。
- 11小節目から手の位置を下げます（⑥弦の C1 を人差し指で押さえる位置）。手の移動が、ラインの区切りと重なっています。
- 各小節の4拍目は、すべて次の小節の1拍目へ半音か全音で近づく音です。

## 練習曲2　Dポジションのマイナー

**関連する章**：第2章

C マイナーのⅡ-Ⅴ-Ⅰを2回まわす8小節です。全体を Dポジションのまま弾きます。G7 はオルタード、Cm6 はメロディック・マイナー、Dm7(♭5) の2回目はロクリアン♮2 で弾いています。

```lilypond {#et2 caption="練習曲2　Dポジションのマイナー"}
<<
  \new ChordNames \chordmode { d1:m7.5- g:7 c:m6 as:maj7 d:m7.5- g:7 c:m6 c:m6 }
  \new Staff {
    \clef bass \time 4/4
    d4\4 f4\3 aes4\3 c'4\2 |
    b4\2 aes4\3 f4\3 des4\4 |
    c4\4 ees4\4 g4\3 a4\3 |
    aes4\3 g4\3 ees4\4 c4\4 | \break
    d4\4 e4\4 f4\3 aes4\3 |
    g4\3 aes4\3 b4\2 des'4\2 |
    c'4\2 b4\2 a4\3 g4\3 |
    ees4\4 g4\3 f4\3 ees4\4 \bar "|."
  }
>>
```

**ポイント**

- 2小節目と6小節目の G7 では、オルタード・スケールの音（A♭、D♭）を使っています。
- 3小節目と7小節目の Cm6 では、メロディック・マイナーの A（長6度）と B（長7度）を聞かせます。
- 1小節目の Dm7(♭5) はコード・トーンだけで弾き、5小節目ではロクリアン♮2 の 9度（E）を加えています。
- 8小節目の最後の E♭2 は、1小節目の D2 に半音上から戻る音です。

## 練習曲3　2拍ごとの着地点

**関連する章**：第3章

B♭ のキーで、2拍ごとにコードが変わる8小節です。各コードの1拍目にルート、2拍目に次のルートへのアプローチを置く形を、8小節続けます。

```lilypond {#et3 caption="練習曲3　2拍ごとの着地点"}
<<
  \new ChordNames \chordmode { bes2:maj7 g:7 c:m7 f:7 d:m7 g:7 c:m7 f:7 f:m7 bes:7 es:maj7 as:7 d:m7 g:7 c:m7 f:7 }
  \new Staff {
    \clef bass \time 4/4
    bes,4\5 aes,4\5 g,4\5 b,4\5 |
    c4\4 e4\4 f4\3 ees4\4 |
    d4\4 a,4\5 g,4\5 des4\4 |
    c4\4 bes,4\5 a,4\5 ges,4\6 | \break
    f,4\6 aes,4\5 bes,4\5 d4\4 |
    ees4\4 g4\3 aes4\3 ees4\4 |
    d4\4 f4\3 g4\3 b,4\5 |
    c4\4 ees4\4 f4\3 a,4\5 \bar "|."
  }
>>
```

**ポイント**

- アプローチの型（第3章 3.2節）を、なるべく毎回変えています。たとえば1小節目は「半音上から」（A♭1 → G1）と「半音下から」（B1 → C2）です。
- 3小節目の D♭2 は、G7 の裏コード D♭7 のルートです（第4章）。
- 4小節目の3拍目は、ルートではなく F7 の3度（A1）から始めています。そのあと G♭1 で、5小節目の F1 へ半音上から近づきます。
- 8小節目の最後の A1 は、1小節目の B♭1 に半音下から戻る音です。

## 練習曲4　裏道を通って

**関連する章**：第4章

C のキーの8小節です。セカンダリー・ドミナントの裏コード（E♭7、D♭7）と、バックドア・ドミナント（Fm7 - B♭7）を使ったリハモの上でウォーキングします。

```lilypond {#et4 caption="練習曲4　裏道を通って"}
<<
  \new ChordNames \chordmode { c1:maj7 es:7 d:m7 des:7 c:maj7 f2:m7 bes:7 c1:maj7 c:maj7 }
  \new Staff {
    \clef bass \time 4/4
    c4\4 e4\4 g4\3 e4\4 |
    ees4\4 g4\3 bes4\2 des'4\2 |
    d'4\2 c'4\2 a4\3 d4\4 |
    des4\4 f4\3 aes4\3 b4\2 | \break
    c'4\2 b4\2 g4\3 e4\4 |
    f4\3 aes4\3 bes4\2 des'4\2 |
    c'4\2 a4\3 g4\3 d4\4 |
    c,1\6 \bar "|."
  }
>>
```

**ポイント**

- 1〜4小節目の1拍目は C → E♭ → D → D♭ と動きます。2小節目から先は、半音ずつ下りるベースラインです。
- 4小節目の最後の B2 は、D♭7 の7度（C♭）で、同時に G7 の3度でもあります（第4章 4.2節）。
- 6小節目はバックドア・ドミナントです。4拍目の D♭3 は B♭7 の♯9度で、7小節目の C3 へ半音上から解決します。
- 最後の小節は、トニックを⑥弦の C1 で鳴らして終わります。

## 練習曲5　ガイドトーンの伴奏

**関連する章**：第5章

F のキーで、4度進行を7つ続ける8小節の伴奏です。1拍目でルートを弾き、2拍目の裏でガイドトーン（3度と7度）を②①弦で弾いて伸ばします（チャールストンのリズム）。

```lilypond {#et5 caption="練習曲5　ガイドトーンの伴奏"}
<<
  \new ChordNames \chordmode { g1:m7 c:7 f:maj7 bes:maj7 e:m7.5- a:7 d:m7 d:m7 }
  \new PianoStaff <<
    \new Staff {
    \clef treble \time 4/4 \set stringNumberOrientations = #'(up)
    r4 r8 <bes\2 f'\1>8~ <bes f'>2 |
    r4 r8 <bes\2 e'\1>8~ <bes e'>2 |
    r4 r8 <a\2 e'\1>8~ <a e'>2 |
    r4 r8 <a\2 d'\1>8~ <a d'>2 | \break
    r4 r8 <d'\2 g'\1>8~ <d' g'>2 |
    r4 r8 <cis'\2 g'\1>8~ <cis' g'>2 |
    r4 r8 <c'\2 f'\1>8~ <c' f'>2 |
    r4 r8 <c'\2 f'\1>8~ <c' f'>2 \bar "|."
    }
    \new Staff {
    \clef bass \time 4/4 \set stringNumberOrientations = #'(down)
    g,4\5 r2. |
    c4\4 r2. |
    f,4\5 r2. |
    bes,4\4 r2. | \break
    e,4\6 r2. |
    a,4\5 r2. |
    d4\4 r2. |
    d4\4 r2. \bar "|."
    }
  >>
>>
```

**ポイント**

- 上声部の2音は、コードが変わるたびに半音か全音で動くか、そのまま残ります（第5章 5.2節）。
- 5小節目で上声部を1オクターブ上に移して、仕切り直しています。そのまま続けると、6小節目の A7 のトライトーンが G2 - C♯3 になり、下の音が目安（B♭2）を下回るためです。
- 4小節目の B♭maj7 の上声部 A2 - D3 は完全4度で、下の音がちょうど目安（A2）です。
- 8分音符はスウィングで弾きます。

## 練習曲6　ドリアンの16小節

**関連する章**：第6章

D ドリアン8小節、E♭ ドリアン4小節、D ドリアン4小節の16小節です。全体を Dポジションのまま弾きます。

```lilypond {#et6 caption="練習曲6　ドリアンの16小節"}
<<
  \new ChordNames \chordmode { d1:m7 d:m7 d:m7 d:m7 d:m7 d:m7 d:m7 d:m7 es:m7 es:m7 es:m7 es:m7 d:m7 d:m7 d:m7 d:m7 }
  \new Staff {
    \clef bass \time 4/4
    d4\4 f4\3 g4\3 a4\3 |
    b4\2 c'4\2 d'4\2 b4\2 |
    a4\3 g4\3 e4\4 f4\3 |
    g4\3 a4\3 b4\2 d'4\2 | \break
    e'4\1 d'4\2 b4\2 a4\3 |
    g4\3 f4\3 e4\4 c4\4 |
    d4\4 b,4\5 a,4\5 g,4\5 |
    a,4\5 b,4\5 c4\4 d4\4 | \break
    ees4\4 ges4\3 bes4\2 c'4\2 |
    des'4\2 c'4\2 bes4\2 ges4\3 |
    aes4\3 bes4\2 c'4\2 ees'4\1 |
    des'4\2 bes4\2 ges4\3 ees4\4 | \break
    d4\4 f4\3 a4\3 b4\2 |
    c'4\2 a4\3 g4\3 e4\4 |
    f4\3 c4\4 a,4\5 e,4\6 |
    d,1\6 \bar "|."
  }
>>
```

**ポイント**

- D ドリアンの部分では、特性音の B を何度も聞かせ、C♯ は一度も使いません（第6章 6.3節）。
- 8小節目は D2 まで上がり、9小節目の E♭2 へ半音下から入ります。E♭ ドリアンの部分では、特性音の C を聞かせます。
- 12小節目の最後の E♭2 は、13小節目の D2 に半音上から戻る音です。
- 15小節目の最後は、導音の C♯ ではなく、全音上の E1 から D1 に着地します。

## 練習曲7　エンクロージャーのソロ

**関連する章**：第7章

F のキーで、8分音符のソロ・ラインを弾く8小節です。小節の変わり目で、次のコードの3度にエンクロージャーで着地します。すべて Dポジションで弾けます。

```lilypond {#et7 caption="練習曲7　エンクロージャーのソロ"}
<<
  \new ChordNames \chordmode { g1:m7 c:7 f:maj7 f:maj7 a:m7.5- d:7 g2:m7 c:7 f1:maj7 }
  \new Staff {
    \clef bass \time 4/4
    g8\3 a8\3 bes8\2 c'8\2 d'8\2 g'8\1 f'8\1 dis'8\1 |
    e'8\1 d'8\2 c'8\2 bes8\2 a8\3 g8\3 bes8\2 gis8\3 |
    a8\3 c'8\2 e'8\1 g'8\1 f'8\1 e'8\1 d'8\2 c'8\2 |
    a2\3 r2 | \break
    r8 a8\3 c'8\2 ees'8\1 g'8\1 ees'8\1 g'8\1 f'8\1 |
    fis'8\1 ees'8\1 d'8\2 c'8\2 bes8\2 a8\3 c'8\2 a8\3 |
    bes8\2 d'8\2 f'8\1 d'8\2 c'8\2 e'8\1 g'8\1 e'8\1 |
    f'2\1 r2 \bar "|."
  }
>>
```

**ポイント**

- 1小節目の最後は F3 → D♯3 → E3（C7 の3度）、2小節目の最後は B♭2 → G♯2 → A2（Fmaj7 の3度）のエンクロージャーです（第7章 7.3節）。
- 4小節目は半分が休符です。前半4小節の区切りで、息つぎを入れています。
- 5小節目の最後は G3 → F3 → F♯3（D7 の3度）、6小節目の最後は C3 → A2 → B♭2（Gm7 の3度）で着地します。
- 7小節目の最後の G3 → E3 → F3 も、最後のトニックの F を上下から挟む形です。

## 練習曲8　ひとりで弾く

**関連する章**：第8章

C のキーで、オリジナルのメロディをソロベースで弾く8小節です。メロディが伸びている小節（1、3、5小節目）ではベースが歩き、メロディが動く小節ではルートを伸ばします。

```lilypond {#et8 caption="練習曲8　ひとりで弾く"}
<<
  \new ChordNames \chordmode { c1:maj7 a:7 d:m7 g:7 e:m7 a:7 d2:m7 g:7 c1:maj7 }
  \new PianoStaff <<
    \new Staff {
    \clef treble \time 4/4 \set stringNumberOrientations = #'(up)
    e'1\1 |
    cis'2\2 e'2\1 |
    f'1\1 |
    f'2\1 d'2\2 | \break
    g'1\1 |
    e'2\1 cis'2\2 |
    f'2\1 b2\2 |
    e'1\1 \bar "|."
    }
    \new Staff {
    \clef bass \time 4/4 \set stringNumberOrientations = #'(down)
    c4\4 g,4\5 b,4\5 bes,4\5 |
    a,1\5 |
    d4\4 a,4\5 f,4\6 aes,4\5 |
    g,1\5 | \break
    e,4\6 g,4\5 b,4\5 bes,4\5 |
    a,1\5 |
    d2\4 g,2\5 |
    c,1\6 \bar "|."
    }
  >>
>>
```

**ポイント**

- メロディの強拍の音は、ほとんどがコードの3度か7度です。ルートを足すだけでコードが聞こえます（第8章 8.2節）。
- 1、3、5小節目では、メロディを①弦で伸ばしたまま、⑥⑤④弦でベースを歩かせます。メロディを押さえる指を先に決めてください。
- 4拍目のアプローチ（1小節目の B♭1、3小節目の A♭1、5小節目の B♭1）は、どれも次のルートへ半音上から近づきます。
- 最後の小節だけ手の位置を下げ、⑥弦の C1 とメロディの E3 を同時に鳴らして終わります。

## 練習曲の使い方のまとめ

| 曲 | 練習すること | 関連する章 |
|---|---|---|
| 1 | 3つの音域を使い分け、Low B を最後にとっておく | 第1章・第3章 |
| 2 | 1つのポジションのまま、マイナーのスケールを切り替える | 第2章 |
| 3 | 2拍ごとのアプローチの型を使い分ける | 第3章 |
| 4 | 裏コードとバックドア・ドミナントの上で歩く | 第4章 |
| 5 | ルートとガイドトーンで伴奏する | 第5章 |
| 6 | モードの特性音を聞かせ、モードの切り替わりを示す | 第6章 |
| 7 | エンクロージャーで3度に着地するソロ | 第7章 |
| 8 | メロディの下でベースを歩かせる | 第8章 |
