# 第3章　ウォーキングベース上級

## 3.1　ラインは「着地点」から逆算する

第2章で、ウォーキングの基本を2つの決まりにまとめました。1拍目にコード・トーンを置くこと、4拍目に次の小節へのアプローチ・ノートを置くことです。この章では、このうち**4拍目の選び方**と、**1コーラス全体のラインの形**を掘り下げます。

ウォーキングの上手なベーシストは、ラインを前から順に考えていません。まず次の小節の1拍目（**着地点**）を決め、そこへどう近づくかを逆算しています。着地点がはっきりしていれば、その手前の音は多少大胆に選んでも、ラインは崩れません。

## 3.2　アプローチ・ノートの6つの型

着地点への近づき方は、次の6つの型に整理できます。譜例3-1は、すべて C2 を着地点にした例です。

| 型 | 着地点の直前に置く音 | 響きの特徴 |
|---|---|---|
| (a) 半音下から | 着地点の半音下 | 最も強い引力。どのコードにも使える |
| (b) 半音上から | 着地点の半音上 | 緊張が強い。ドミナントの♭5度（裏コードのルート）と重なることが多い |
| (c) スケールの隣の音から | スケール上で隣にある音 | 最も穏やか。歌うようなラインになる |
| (d) 5度上（4度下）から | 着地点の5度上の音 | ドミナントからトニックへの進行を、ベース1音で示す |
| (e) ダブル・クロマチック | 着地点の全音上から半音ずつ2つ | 3拍目から着地を予告する。テンポが速いときに効く |
| (f) エンクロージャー | 着地点の上と下から挟む | ビバップの語法。着地点がいっそう強調される |

```lilypond {#ex3-1 caption="譜例3-1　アプローチ・ノートの6つの型（着地点はすべて C2）"}
\new Staff {
  \clef bass
  \time 2/4
  b,4\4^"(a)" c\4 \bar "||"
  des4\4^"(b)" c\4 \bar "||"
  d4\4^"(c)" c\4 \bar "||"
  g,4\5^"(d)" c\4 \bar "||"
  \time 3/4
  d4\4^"(e)" des\4 c\4 \bar "||"
  des4\4^"(f)" b,\4 c\4 \bar "|."
}
```

(a)〜(f) は、すべて④弦の2〜5フレットと⑤弦の3フレットだけで弾けます。6弦ベースでは、どの着地点にも上下両側から近づけるので、着地点のまわりの音を手の形として覚えておくと、型をすぐに使い分けられます。

型を選ぶときの目安は次の通りです。

- 迷ったら (a)。どの場面でも外れない。
- 次のコードがドミナントなら (b)。裏コードの響きを先取りできる。
- バラードやツー・フィールでは (c)。
- 曲の区切り（8小節目、16小節目）の手前では (d) や (f) で、着地を強く示す。

## 3.3　2拍ごとにコードが変わるとき

1小節に2つのコードがあるときは、2拍ごとに着地点が来ます。このときは「1拍目にルート、2拍目にアプローチ」を2回繰り返すのが基本です。

譜例3-2は、F のキーのターンアラウンド（Gm7 - C7 - Fmaj7 - D7）を2回まわした例です。

```lilypond {#ex3-2 caption="譜例3-2　2拍ごとのアプローチ（Fのターンアラウンド）"}
<<
  \new ChordNames \chordmode {
    g2:m7 c:7 f:maj7 d:7 g:m7 c:7 f1:maj7
  }
  \new Staff {
    \clef bass \time 4/4
    g,4\5 bes,\4 c\4 e\3 | f\3 es\3 d\3 aes,\5 |
    g,4\5 des\4 c\4 e,\6 | f,\5 a,\4 c\4 d\4 \bar "||"
  }
>>
```

2拍目と4拍目のアプローチを、型の名前で読んでみます。

| 小節 | 2拍目 → 着地点 | 4拍目 → 着地点 |
|---|---|---|
| 1 | B♭1 → C2（c：スケールの隣） | E2 → F2（a：半音下） |
| 2 | E♭2 → D2（b：半音上） | A♭1 → G1（b：半音上） |
| 3 | D♭2 → C2（b：半音上） | E1 → F1（a：半音下） |

2小節目の4拍目の A♭ は、D7 の♭5度です。第2章で見たように、これは D7 の裏コード（A♭7）のルートでもあります。D2 から A♭1 へのトライトーンの跳躍は、ベーシストがよく使う「裏コードを1音でほのめかす」方法です。

3小節目では、4拍目に E1（⑥弦）まで下りて、4小節目の F1 に着地しています。最後の Fmaj7 では、F1 から上行して中域に戻ります。第1章で見た「低域には着地して、すぐ離れる」の応用です。

## 3.4　1コーラスを1つの山として設計する

1小節ずつのアプローチが上手でも、ラインが同じ音域を行き来するだけでは、聴き手は退屈します。上級のウォーキングでは、**8小節、16小節、1コーラスといった大きな単位で、ラインの輪郭（コントゥア）を設計**します。

譜例3-3は、8小節の進行（Fm7 - B♭7 - E♭maj7 - A♭maj7 - Dm7(♭5) - G7 - Cm6）を、1つの山として設計した例です。

```lilypond {#ex3-3 caption="譜例3-3　8小節を1つの山にしたライン"}
<<
  \new ChordNames \chordmode {
    f1:m7 bes:7 es:maj7 as:maj7
    d:m7.5- g:7 c:m6 c:m6
  }
  \new Staff {
    \clef bass \time 4/4
    f,4\6 g,\5 aes,\5 c\4 | d\4 f\3 aes\3 d'\2 |
    es'4\1 d'\2 bes\2 g\3 | aes\3 g\3 es\4 cis\4 | \break
    d4\4 c\4 aes,\5 f,\6 | g,\5 f,\6 d,\6 des,\6 |
    c,4\6 es,\6 g,\5 a,\5 | c\4 b,\5 a,\5 g,\5 \bar "||"
  }
>>
```

ラインの形を言葉にすると、次のようになります。

- **1〜2小節目（上り）**：中域の F1 から上行し、2小節目の最後で D3 に達します。
- **3小節目（頂上）**：①弦の E♭3 が、この8小節で最も高い音です。トニック・メジャー（E♭maj7）を頂上に置いています。
- **4〜6小節目（下り）**：少しずつ下降し、6小節目では⑥弦に入ります。
- **7小節目（着地）**：トニック・マイナー（Cm6）を、⑥弦1フレットの C1 で迎えます。8小節で最も低い音です。
- **8小節目（戻り）**：すぐに中域に戻り、次の8小節に備えます。

1小節目から6小節目の3拍目までは、すべてポジションⅢ（⑥弦3〜7フレット）の中にあります。6小節目の D♭1 で初めてポジションを下げ、7小節目の C1 に着地します。**手の移動を、ラインの山場に合わせている**ことに注目してください。手の位置が変わる瞬間は、聴き手にもラインの区切りとして伝わります。

### コーラスごとの音域の計画

ソロの伴奏で何コーラスも弾くときは、コーラスごとに使う音域を変えると、バンド全体の盛り上がりを作れます。次の表は、計画の一例です。

| コーラス | 中心の音域 | 使う弦 | ねらい |
|---|---|---|---|
| テーマ | 中域 | ⑤④③ | 曲の形をはっきり示す |
| ソロ1コーラス目 | 中域 | ⑤④③ | ソリストに場所を空ける |
| ソロ2コーラス目 | 中域〜高域 | ④③②① | 動きを大きくして、ソリストを押し上げる |
| ソロ最後のコーラス | 低域〜高域 | 全弦 | Low B を解禁し、音域の幅で山場を作る |
| 最後のテーマ | 中域、最後だけ低域 | ⑤④③、最後に⑥ | エンディングのトニックを Low B の音域で鳴らす |

ポイントは、**Low B を最初から使わない**ことです。⑥弦の低い音は、とっておくほど効果が大きくなります。

## 3.5　Low B の使いどころ

Low B 弦の開放から4フレットまで（B0〜D♯1）は、4弦ベースにない音域です。この音域が特に生きるのは、次の場面です。

1. **トニックへの着地**：キーが C、D♭、D、E♭ の曲では、トニックのルートを⑥弦で鳴らせます。B のキーなら開放弦です。
2. **ツー・フィール**：テーマのAメロなどで、2分音符でルートと5度を弾く場面です。音数が少ないので、低い音でも輪郭が失われません。
3. **ペダル・ポイント**：イントロやエンディングで、同じ低音を伸ばし続ける場面です。
4. **エンディングの最後の音**。

反対に、次の場面では使わないほうがよいでしょう。

- テンポの速い曲で、8分音符が続く部分。低い音は立ち上がりが遅く、リズムがぼやけます。
- ピアノの左手が低いオクターブを弾いているとき。音域がぶつかって、低音が濁ります。
- 響きの多い会場。低い周波数ほど部屋に残り、ラインの輪郭が消えます。

譜例3-4は、E♭ のキーで Low B を使ったツー・フィールの例です。

```lilypond {#ex3-4 caption="譜例3-4　Low B を使ったツー・フィール（E♭のキー）"}
<<
  \new ChordNames \chordmode { es1:maj7 c:m7 f:m7 bes:7 }
  \new Staff {
    \clef bass \time 4/4
    es,2\6 bes,\4 | c,\6 g,\5 | f,\6 c\4 | bes,\4 d,\6 \bar "||"
  }
>>
```

E♭1、C1、F1 という低いルートに対して、2拍目の音（B♭1、G1、C2）を中域に置いています。低いルートの後に1オクターブ近く上の音を置くと、低域の重さと中域の輪郭が両立します。4小節目の最後の D1 は、B♭7 の3度で、最初の E♭1 へ半音下から近づくアプローチ・ノートです。

## 3.6　リズムの変化

4分音符だけのウォーキングは、上級になるほど単調に聞こえやすくなります。ラインに表情を付けるために、次の2つの変化を覚えておきましょう。

- **スキップ・ノート**：1拍を8分音符2つに割り、2つ目を音程のない「ゴースト・ノート」（譜面では×の符頭）にします。ドラムのハイハットのような、軽いはずみが生まれます。
- **3連符のレイク**：1拍の中に3連符を入れて、着地点へ駆け上がります。

譜例3-5は、この2つを使った例です。

```lilypond {#ex3-5 caption="譜例3-5　スキップ・ノートと3連符"}
<<
  \new ChordNames \chordmode { f1:7 bes:7 }
  \new Staff {
    \clef bass \time 4/4
    f,4\5 a,8\5 \xNote a,8\5 c4\4 es\4 |
    bes,4\4 \tuplet 3/2 { bes,8\4 c\4 cis\4 } d4\4 e\4 \bar "||"
  }
>>
```

1小節目では、2拍目の A1 の後にゴースト・ノートを入れています。左手は A1 を押さえたまま力を抜き、右手で同じ弦を弾きます。2小節目では、2拍目の3連符で B♭1 から D2 まで半音で駆け上がります。どちらも**1コーラスに数回まで**にとどめてください。使いすぎると、ラインの推進力がかえって失われます。

## 3.7　練習課題

1. 譜例3-1の6つの型を、F2、B♭1、E♭2 を着地点にして弾いてください。すべて1つのポジションの中で弾ける運指を探します。
2. 譜例3-2と同じ進行で、2拍目と4拍目のアプローチを、毎回違う型にして4回まわしてください。
3. 譜例3-3と同じ8小節で、「頂上」を5小節目に、「着地」を8小節目に移したラインを作ってください。
4. 手持ちのスタンダード曲を1つ選び、3.4節の表のように、テーマからエンディングまでのコーラスごとの音域の計画を立ててください。計画に沿って、Low B を使う場所を2か所以内に絞ります。
5. 譜例3-4の進行を、4分音符のウォーキングに変えて弾いてください。1〜2コーラス目はツー・フィール、3コーラス目からウォーキングに切り替えます。

## 3.8　まとめ

- ラインは次の小節の1拍目（着地点）から逆算して作る。
- アプローチ・ノートは6つの型に整理できる。迷ったら半音下から。
- 2拍ごとにコードが変わるときは、「ルート＋アプローチ」を2回繰り返す。
- 8小節、1コーラスの単位で、ラインの山と着地を設計する。手の移動をラインの山場に合わせる。
- Low B は最初から使わず、トニックへの着地、ツー・フィール、エンディングのためにとっておく。
- スキップ・ノートや3連符は、1コーラスに数回までにとどめる。
