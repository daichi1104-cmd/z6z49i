# 第1章　6弦ベースの音域とレジスター設計

## 1.1　なぜ6弦でジャズ理論を学ぶのか

ジャズ理論の本の多くは、ピアノの鍵盤を前提に書かれています。コード・スケールもヴォイシングも、鍵盤の上なら一目で見えます。ところが4弦ベースの指板に移すと、1オクターブを超えるたびにポジション移動が必要になり、「理論として分かっていること」と「指板の上で弾けること」の間に溝ができます。中級から上級に進むベーシストが伸び悩む原因の多くは、この溝にあります。

6弦ベースは、この溝を埋めるのに向いた楽器です。1つのポジションで2オクターブと長3度を押さえられるので、スケールやアルペジオ、ヴォイシングを「1つの手の形」として覚えられます。本書では、理論を説明するたびに、それを6弦の指板の上でどう形にするかを示します。

ただし、弦が多いことは、そのまま音楽の良さにはつながりません。低すぎる音は輪郭がぼやけ、高すぎる音はピアノやギターとぶつかります。6弦ベースでジャズを弾くには、まず**どの音域で何を弾くか**を設計する力が必要です。この章では、その土台を作ります。

## 1.2　本書の表記ルール

本書では次の決まりで記譜します。

- **チューニング**は低い方から B-E-A-D-G-C です。弦番号は高い方から①（C弦）〜⑥（B弦）と呼びます。
- **記譜は実音の1オクターブ上**です。コントラバスやエレクトリック・ベースの一般的な記譜と同じです。本文で音の高さを英字と数字（C3 など）で示すときは、特に断りがなければ**実音**です。
- 譜例では、音符の近くの丸数字で**弾く弦**を示します。フレットは書きません。同じ音を別の弦で弾くと音色も運指も変わるので、弦の指定は理論の一部だと考えてください。

開放弦の実音と記譜音は次の通りです。①弦の開放は、記譜すると中央のド（C4）になります。

| 弦 | ⑥ | ⑤ | ④ | ③ | ② | ① |
|---|---|---|---|---|---|---|
| 開放弦 | B | E | A | D | G | C |
| 実音 | B0 | E1 | A1 | D2 | G2 | C3 |
| 記譜音 | B1 | E2 | A2 | D3 | G3 | C4 |

```lilypond {#ex1-1 caption="譜例1-1　開放弦の記譜（実音の1オクターブ上）"}
\new Staff \with { \omit TimeSignature } {
  \clef bass \cadenzaOn
  b,,1\6 e,1\5 a,1\4 d1\3 g1\2 c'1\1
  \bar "|."
}
\addlyrics { B E A D G C }
```

## 1.3　3つのレジスター

6弦ベースが出せる音は、実音で B0 から C5 前後まで、およそ4オクターブです（最高音は楽器によって変わります）。本書ではこの音域を、役割によって3つのレジスターに分けて考えます。

| レジスター | 実音のおよその範囲 | 主な役割 |
|---|---|---|
| 低域 | B0〜D♯1 | ルートを1オクターブ下に落とす、ラインの着地点 |
| 中域 | E1〜G2 | ウォーキング、ルートの提示（伝統的なベースの音域） |
| 高域 | G2〜C5 | ガイドトーン、ヴォイシング、ソロ、メロディ |

**低域**は⑥弦でしか出せない音域で、4弦ベースにはありません。ここは常用する場所ではありません。ラインが下降してきたときの着地点や、曲の山場でルートを1オクターブ下に落とす場所として、**ここぞというときに使う**のが基本です。

**中域**は、コントラバスのウォーキングが伝統的に使ってきた音域です。リズム・セクションの中でベースが最も自然に聞こえる場所で、本書の譜例でもラインの中心はここに置きます。

**高域**は、ピアノの左手やギターのコードと重なる音域です。6弦ベースの可能性が最も広がる場所ですが、ほかの楽器と最もぶつかりやすい場所でもあります。ピアニストの左手のヴォイシングは、おおむね C3〜C4 のあたりに集まります。バンドにピアノやギターがいるときは、このあたりで3度や7度を鳴らす前に、相手が何を弾いているかを聴いてください。

## 1.4　1ポジションで2オクターブ

4弦ベースの1ポジション（人差し指から小指までの4フレット幅）で届く範囲は、1オクターブと増4度です。6弦ベースでは、同じ手の幅で2オクターブと長3度に届きます。

譜例1-2は、Cメジャー・スケールを C1 から C3 まで、ポジション移動なしで弾く例です。開放弦を含むローポジションなので、最も覚えやすい形です。

```lilypond {#ex1-2 caption="譜例1-2　Cメジャー・スケール2オクターブ（ポジション移動なし）"}
\new Staff {
  \clef bass \time 4/4
  c,4\6 d,\6 e,\5 f,\5 | g,\5 a,\4 b,\4 c\4 |
  d\3 e\3 f\3 g\2 | a\2 b\2 c'2\1 \bar "|."
}
```

この「2オクターブを1つの形で持つ」感覚が、後の章のすべての土台になります。第2章ではこの考え方を、開放弦を使わない形と、すべてのコード・スケールに広げます。

## 1.5　低域を使ったウォーキング

譜例1-3は、Ⅱ-Ⅴ-Ⅰ（Dm7 - G7 - Cmaj7）のウォーキングです。ラインは D2 から階段状に下り、3小節目の頭で C1 に着地します。D1、C1、C♯1 の3つの音は、4弦ベースでは出せない音です。

```lilypond {#ex1-3 caption="譜例1-3　低域に着地するウォーキング（Ⅱ-Ⅴ-Ⅰ）"}
<<
  \new ChordNames \chordmode { d1:m7 g:7 c:maj7 c:maj7 }
  \new Staff {
    \clef bass \time 4/4
    d4\4 c\4 b,\4 a,\5 | g,\5 f,\5 e,\6 d,\6 |
    c,\6 e,\6 g,\5 b,\4 | c\4 g,\5 e,\6 cis,\6 \bar "||"
  }
>>
```

注目してほしい点が2つあります。

1つ目は、**着地点の重み**です。4弦ベースでこのラインを弾くと、2小節目の E1 から先は1オクターブ上に跳ぶしかなく、下降の流れが途切れます。6弦ベースなら下降をそのまま続けて、トニックを最も低い C1 で迎えられます。聴き手にはこれが、トニックに着いたというはっきりした手ごたえになります。

2つ目は、**低域にとどまらない**ことです。3小節目では C1 に着地したあと、すぐにアルペジオで中域に戻っています。低域の音は倍音が少なく、続けて弾くと音程の輪郭が失われます。低域は「着地して、すぐ離れる」場所だと考えてください。4小節目の最後の C♯1 は、次の小節の Dm7 へ半音下から近づくアプローチ・ノートです。アプローチ・ノートは第3章で詳しく扱います。

## 1.6　高域とロー・インターバル・リミット

高域で2つ以上の音を同時に鳴らすときに知っておきたいのが、**ロー・インターバル・リミット**（低音域での音程の限界）です。同じ音程でも、低い音域で鳴らすほど倍音がぶつかり合い、濁って聞こえます。表は、音程ごとに「下の音をこれより低くすると濁りやすい」とされる高さです。一般に引用される目安で、楽器や音色によって変わります。

| 音程 | 下の音の目安（実音） | 音程 | 下の音の目安（実音） |
|---|---|---|---|
| 短2度 | E3 | 増4度（トライトーン） | B♭2 |
| 長2度 | E♭3 | 完全5度 | B♭1 |
| 短3度 | C3 | 短6度 | G2 |
| 長3度 | B♭2 | 長6度 | F2 |
| 完全4度 | A2 | 短7度・長7度 | F2 |

①弦の開放が C3 なので、6弦ベースでは**3度より狭い音程は、ほぼ①②弦の上でしか澄んで鳴らない**ことが分かります。完全5度は B♭1 まで下げられるので、5度のダブルストップ（パワーコード）は低い弦でも使えます。ベースで和音を弾くときの音程の選び方は、ほぼこの表で決まります。

譜例1-4は、Ⅱ-Ⅴ-Ⅰで3度と7度（ガイドトーン）を②①弦で鳴らす例です。各小節の頭でルートを弾いてから、ダブルストップを伸ばします。

```lilypond {#ex1-4 caption="譜例1-4　ガイドトーンのダブルストップ（②①弦）"}
<<
  \new ChordNames \chordmode { d1:m7 g:7 c:maj7 }
  \new Staff {
    \clef bass \time 4/4
    d4\4 <c'\2 f'\1>2. | g,4\5 <b\2 f'\1>2. | c4\4 <b\2 e'\1>2. \bar "|."
  }
>>
```

ダブルストップは、Dm7 では C3 と F3（完全4度）、G7 では B2 と F3（トライトーン）、Cmaj7 では B2 と E3（完全4度）です。どれも表の目安より上にあるので、濁らずに鳴ります。上の声部は、C→B、F→F→E と、ほとんど動かずにつながっています。これがガイドトーンの**ヴォイス・リーディング**（声部の進み方）で、第5章の中心になる考え方です。

ルートは4分音符で切ってください。ルートの D2 と7度の C3 を一緒に伸ばすと、短7度の目安（F2）を下回るので、低音が濁ります。

## 1.7　練習課題

1. 譜例1-2を、開放弦を使わずに弾いてください。⑥弦の G1 から始めて、Gメジャー・スケールを2オクターブ、ポジション移動なしで弾きます。
2. 譜例1-3のラインを、キーを F と B♭ に移して弾いてください。どちらのキーでも、トニックが低域に着地するようにラインを組み直します。
3. 譜例1-4のダブルストップを、F（Gm7 - C7 - Fmaj7）と B♭（Cm7 - F7 - B♭maj7）で作ってください。すべての音程が表の目安より上にあることを確かめます。
4. 手持ちのスタンダード曲のコード譜を1つ選び、各コードのルートを「低域・中域・高域」のどこで弾くかを決めて書き込んでください。曲の構成（Aメロ、サビ、最後のコーラス）に合わせて、レジスターを計画的に変えます。

## 1.8　まとめ

- 6弦ベースは1ポジションで2オクターブと長3度に届く。理論を「手の形」として覚えられる。
- 音域を低域・中域・高域の3つに分けて、役割を決めて使う。
- 低域は着地点として使い、すぐに離れる。
- 高域で和音を弾くときは、ロー・インターバル・リミットを目安にする。3度より狭い音程は、ほぼ①②弦の上でしか澄んで鳴らない。
