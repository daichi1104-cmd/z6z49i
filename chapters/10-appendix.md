# 付録

## 付録A　音名の表記

本書では、音の高さを**国際式**の音名で示しています。中央のド（ピアノの真ん中の C）を C4 とする方式です。日本では、中央のドを C3 とする**ヤマハ式**も広く使われています。ヤマハ式に慣れている方は、本書の数字に1を引いて読み替えてください。

| | 国際式（本書） | ヤマハ式 |
|---|---|---|
| 中央のド | C4 | C3 |
| ①弦の開放（実音） | C3 | C2 |
| ②弦の開放（実音） | G2 | G1 |
| ③弦の開放（実音） | D2 | D1 |
| ④弦の開放（実音） | A1 | A0 |
| ⑤弦の開放（実音） | E1 | E0 |
| ⑥弦の開放（実音） | B0 | B-1 |

## 付録B　スケール一覧と運指

本書で扱ったスケールを、すべて D を主音にして並べました。どのスケールも、実音 D1 から D3 までの2オクターブを、Dポジション（⑥弦の D1 に人差し指を置いた手の位置）のまま弾けます。丸数字は弾く弦です。

主音を D 以外にしたいときは、指の形を保ったまま、手の位置ごとずらしてください。

## 付録C　用語集

本書で使った主な用語を、五十音順に並べました。

| 用語 | 意味 | 主に扱う章 |
|:----------|:------------------------------|:------|
| アウトサイド | コードやモードから意図的に外れた音で緊張を作り、元に戻って解決する語法。 | 第7章 |
| アヴォイド・ノート | コード・トーンの半音上にあり、長く鳴らすとコードの響きを濁らせる音。経過音としては使える。 | 第2章 |
| アッパー・ストラクチャー・トライアド | コードの上に別の三和音を重ねて、テンションを含む響きを作る方法。 | 第5章 |
| アプローチ・ノート | 次の着地点（多くは次の小節の1拍目）の直前に置き、着地点へ導く音。 | 第3章 |
| ヴァンプ | 短いリズム・パターンを繰り返して、ソリストの土台を作る伴奏。 | 第6章 |
| ウォーキング・ベース | 主に4分音符でコードの音をつないでいくベースライン。 | 第2章・第3章 |
| ヴォイス・リーディング | 和音の各声部が、コードが変わるときにどう動くか。なめらかに動かすのが基本。 | 第1章・第5章 |
| 裏コード | あるドミナント7thコードと、ルートがトライトーン離れたドミナント7thコード。3度と7度を共有する。 | 第4章 |
| エンクロージャー | 目標の音を、スケール上の1つ上の音と半音下の音で挟んでから着地する語法。 | 第3章・第7章 |
| ガイドトーン | コードの3度と7度。コードの性格を決める音。 | 第1章・第5章 |
| 記譜音 | 譜面に書かれている音の高さ。本書では実音の1オクターブ上。 | 第1章 |
| コード・スケール | あるコードの上で使えるスケール。コード・トーン、テンション、アヴォイド・ノートからなる。 | 第2章 |
| コード・トーン | コードを構成する1度、3度、5度、7度。 | 第2章 |
| コルトレーン・チェンジ | トニックを長3度ずつ3つに分け、それぞれの前にドミナントを置いて回る進行。 | 第4章 |
| サイドステップ | フレーズの形を保ったまま、半音上か半音下にずらすアウトサイドの方法。 | 第7章 |
| 実音 | 実際に鳴る音の高さ。本書で音の高さを英字と数字で示すときは、特に断りがなければ実音。 | 第1章 |
| スキップ・ノート | 1拍を8分音符2つに割り、2つ目を音程のないゴースト・ノートにするリズムの変化。 | 第3章 |
| セカンダリー・ドミナント | ダイアトニック・コードの前に置く、そのコードへのドミナント。 | 第4章 |
| ソロベース | ベース1本で、ベース・内声・メロディを同時に受け持って演奏すること。 | 第8章 |
| ダブル・クロマチック | 着地点の全音上から半音ずつ2つの音で近づくアプローチ。 | 第3章 |
| ダブルストップ | 2つの音を同時に鳴らすこと。 | 第1章・第5章 |
| チャールストン | 1拍目と2拍目の裏を打つ、ジャズの基本的な伴奏のリズム。 | 第5章 |
| ツー・フィール | 2分音符を中心にしたベースの弾き方。主にルートと5度を弾く。 | 第3章 |
| Dポジション | ⑥弦の D1 に人差し指を置いた手の位置。実音 D1〜G3 を半音階ですべて押さえられる。 | 第2章 |
| テンション | コードに重ねて色を足す9度、11度、13度（およびその変化音）。 | 第2章 |
| 特性音 | あるモードを、ほかのモードと区別する音。ドリアンなら長6度。 | 第6章 |
| バックドア・ドミナント | Ⅴ7 の代わりに♭Ⅶ7 を使ってⅠに解決する進行。 | 第4章 |
| ビバップ・スケール | 7音のスケールに経過音を1つ足し、8分音符で下りたときにコード・トーンが拍の頭に来るようにしたスケール。 | 第7章 |
| ペダル・ポイント | ベースが同じ音を弾き続け、その上で和音が動く書法。 | 第6章 |
| モード | スケールの一種で、主音と音の並びによって独自の響きを持つもの。ドリアン、リディアンなど。 | 第6章 |
| モチーフ | ソロや曲の素材となる短いフレーズ。反復や変形で育てる。 | 第7章 |
| リハーモナイゼーション | メロディはそのままに、コード進行を別のものに置き換えること。リハモ。 | 第4章 |
| レジスター | 音域。本書では低域・中域・高域の3つに分けて扱う。 | 第1章 |
| ロー・インターバル・リミット | 同じ音程でも、低い音域で鳴らすと濁って聞こえる限界の目安。 | 第1章・第5章 |
