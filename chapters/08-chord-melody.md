# 第8章　コードメロディとソロベース

## 8.1　1本のベースで、3つの役割を受け持つ

**ソロベース**とは、ベース1本で曲を演奏することです。そのとき、ベースは次の3つの役割を同時に受け持ちます。

| 役割 | 担当する弦 | 内容 |
|---|---|---|
| ベース | ⑥⑤④弦 | コードのルートや、ウォーキング・ライン |
| 内声 | ④③②弦 | コードの3度や7度（ガイドトーン） |
| メロディ | ②①弦 | 曲のメロディ |

4弦ベースでもソロベースはできますが、ベースとメロディの間に十分な距離をとるのは難しく、どちらかを犠牲にしがちです。6弦ベースなら、⑥⑤弦の低いルートと、①②弦の高いメロディを同時に鳴らしても、2オクターブ以上の距離をとれます。**ベースとメロディの距離が広いほど、ロー・インターバル・リミットに引っかからずに、間に内声を入れる余地が生まれます**。

この章では、オリジナルの4小節のメロディを1つ使い、2声、3声、そしてメロディの下でベースが歩く形へと、編曲を少しずつ厚くしていきます。

## 8.2　まず2声で：ルートとメロディ

ソロベースの編曲は、**メロディとルートの2声**から始めます。2声だけでも、ベースとメロディの距離が十分にあれば、コード進行ははっきり聞こえます。

譜例8-1は、Ⅱ-Ⅴ-Ⅰ（Dm7 - G7 - Cmaj7）の上の4小節のメロディに、ルートを付けた例です。上の段（ト音記号）がメロディ、下の段（ヘ音記号）がルートで、どちらも実音の1オクターブ上に記譜しています。

```lilypond {#ex8-1 caption="譜例8-1　2声：ルートとメロディ"}
<<
  \new ChordNames \chordmode { d1:m7 g:7 c:maj7 c:maj7 }
  \new PianoStaff <<
    \new Staff {
      \clef treble \time 4/4 \set stringNumberOrientations = #'(up)
      f'2\1 e'4\1 d'\2 | b2\2 c'4\2 d'\2 | e'1\1 | g'2\1 e'\1 \bar "|."
    }
    \new Staff {
      \clef bass \time 4/4 \set stringNumberOrientations = #'(down)
      d,1\6 | g,1\5 | c1\4 | c2\4 g,\5 \bar "|."
    }
  >>
>>
```

メロディは F - E - D、B - C - D、E、G - E と動きます。ルートは各小節の1拍目で鳴らし、そのまま伸ばします。

ルートとメロディの関係を見てください。1小節目の D1 と F3、2小節目の G1 と B2、3小節目の C2 と E3 は、どれもルートの上にコードの3度が鳴る形です。**メロディの強拍に3度や7度が来る小節では、ルートを足すだけでコードの響きが完成します**。メロディを書くとき、あるいは編曲する曲を選ぶときは、この点を意識すると、少ない音で豊かに聞こえる編曲になります。

すべての音は、Dポジション（⑥弦の D1 に人差し指を置いた手の位置）の中で押さえられます。ルートを伸ばしたまま、メロディを弾けます。

## 8.3　3声へ：内声を加える

次に、ルートとメロディの間に**内声**を加えます。内声には、コードの3度か7度のうち、メロディにない方を選ぶのが基本です。

譜例8-2では、下の段に内声とルートの2声を書いています。上向きの符尾が内声、下向きの符尾がルートです。

```lilypond {#ex8-2 caption="譜例8-2　3声：ルート・内声・メロディ"}
<<
  \new ChordNames \chordmode { d1:m7 g:7 c:maj7 c:maj7 }
  \new PianoStaff <<
    \new Staff {
      \clef treble \time 4/4 \set stringNumberOrientations = #'(up)
      f'2\1 e'4\1 d'\2 | b2\2 c'4\2 d'\2 | e'1\1 | g'2\1 e'\1 \bar "|."
    }
    \new Staff <<
      \clef bass \time 4/4
      \new Voice {
        \voiceOne \set stringNumberOrientations = #'(up)
        c'2\2 s2 | s1 | b1\2 | b1\2
      }
      \new Voice {
        \voiceTwo \set stringNumberOrientations = #'(down)
        d,1\6 | g,1\5 | c1\4 | c2\4 g,\5 \bar "|."
      }
    >>
  >>
>>
```

小節ごとに、内声の選び方を見ていきます。

| 小節 | メロディ（強拍） | 内声 | メロディと内声の音程 |
|---|---|---|---|
| 1（Dm7） | F（3度） | C3（7度） | 完全4度 |
| 2（G7） | B（3度） | なし | ― |
| 3（Cmaj7） | E（3度） | B2（7度） | 完全4度 |
| 4（Cmaj7） | G → E | B2（7度） | 短6度 → 完全4度 |

2小節目に内声がないことに注目してください。G7 のメロディは B2（3度）なので、内声には7度の F を入れたいところです。ところが、B2 の下に F を入れると F2 - B2 のトライトーンになり、下の音がロー・インターバル・リミットの目安（B♭2）を下回って濁ります。**メロディが低い小節では、内声を省く**。これがソロベースの編曲の重要な判断です。内声を省いても、ルートとメロディの3度だけでコードは十分に聞こえます。

1小節目の内声 C3 は、メロディが2拍伸ばす F3 の下で鳴らし、3拍目で離します。4拍目のメロディ D3 が、内声と同じ②弦で鳴るからです。**同じ弦の上では2つの音を同時に鳴らせない**ので、弦の割り当ては、音を書いたあとに必ず確かめてください。

## 8.4　メロディの下でベースを歩かせる

ソロベースで最も聴きごたえのある形は、**メロディを伸ばしている間に、ベースがウォーキングで動く**形です。メロディとベース・ラインが同時に進むので、2人で演奏しているように聞こえます。

この形が使えるのは、メロディが2分音符や全音符で伸びている場面です。譜例8-3では、譜例8-1のメロディの下で、ベースが4分音符で歩いています。

```lilypond {#ex8-3 caption="譜例8-3　メロディの下でベースを歩かせる"}
<<
  \new ChordNames \chordmode { d1:m7 g:7 c:maj7 c:maj7 }
  \new PianoStaff <<
    \new Staff {
      \clef treble \time 4/4 \set stringNumberOrientations = #'(up)
      f'1\1 | b1\2 | e'1\1 | g'2\1 e'\1 \bar "|."
    }
    \new Staff {
      \clef bass \time 4/4 \set stringNumberOrientations = #'(down)
      d,4\6 f,\6 a,\5 c\4 | g,\5 b,\5 d\4 des\4 |
      c\4 e\4 g\3 e\4 | c\4 b,\5 a,\5 g,\5 \bar "|."
    }
  >>
>>
```

メロディは、譜例8-1を単純にして、各小節で1つか2つの音を伸ばす形にしています。その下でベースは、第3章で学んだウォーキングの決まりどおりに動きます。

- 1小節目：Dm7 のアルペジオ（D - F - A - C）で上がります。
- 2小節目：G7 のアルペジオで上がり、4拍目の D♭2 で C2 へ半音上から近づきます（第3章のアプローチの型 b）。
- 3〜4小節目：Cmaj7 のコード・トーンを動き、4小節目は G1 まで下ります。最後の G1 は、もう一度 Dm7 に戻るときの D1 への足がかりになります。

この形を弾くときは、**メロディの音を押さえる指を決めてから、残りの指でベースを弾く**順番で運指を考えます。メロディの音を押さえる指が動いてしまうと、メロディが途切れます。譜例8-3では、メロディの音をすべて Dポジションの中に置いているので、手の位置を変えずにメロディを伸ばしたまま、ベースを歩かせられます。

## 8.5　編曲の手順

ソロベースの編曲は、次の手順で進めると迷いません。

1. **メロディの音域を決める。** メロディ全体が①②弦（必要なら③弦）に収まるキーとオクターブを選ぶ。
2. **ルートを付ける。** 各コードの1拍目にルートを置き、2声で弾いてみる。この段階でコード進行が聞こえるかを確かめる。
3. **内声を加える。** メロディが伸びている場所に、3度か7度のうちメロディにない方を加える。メロディが低い場所では省く。
4. **ベースを歩かせる場所を決める。** メロディが長く伸びる小節を選び、ウォーキングにする。
5. **弦と手の位置を確かめる。** 同時に鳴る音が別々の弦にあるか、手の位置を変えずに押さえられるかを確かめる。押さえられない場所は、内声を省くか、ルートの音域を変える。
6. **減らす。** 最後に、なくても困らない音を削る。ソロベースでは、音が少ないほうが、1つひとつの音が生きる。

### キーの選び方

ソロベースでは、キーの選び方が編曲のしやすさを大きく左右します。曲の元のキーにこだわらず、次の条件を満たすキーを探してください。

- メロディの最も低い音が、ルートとの間に内声を入れられる高さにある（目安として、メロディの大部分が C3 より上）。
- 主なコードのルートが、⑥⑤弦の弾きやすい位置にある。
- トニックのルートを、⑥弦の低い音域で鳴らせる（キーが B、C、D♭、D、E♭ なら、トニックのルートを⑥弦の B0〜D♯1 の音域で鳴らせる）。

## 8.6　練習課題

1. 譜例8-1のメロディとルートを、F のキー（Gm7 - C7 - Fmaj7）に移してください。メロディが①②弦に収まるオクターブを選びます。
2. 譜例8-2の2小節目に内声を入れる方法を考えてください。メロディをどう変えれば、内声の F を目安より上に置けるかを探します。
3. 譜例8-3のベース・ラインを、2小節目と4小節目だけ別のラインに変えてください。メロディの音を押さえる指は変えません。
4. 自分で4小節のメロディを作り、8.5節の手順1〜6に沿って、ソロベースの編曲をしてください。
5. 手持ちのスタンダード曲を1曲選び、8.5節の「キーの選び方」の条件を満たすキーを探してください。元のキーとの違いを書き出します。

## 8.7　まとめ

- ソロベースでは、⑥⑤④弦でベース、④③②弦で内声、②①弦でメロディを受け持つ。6弦ベースは、ベースとメロディの距離を広くとれる。
- 編曲は、メロディとルートの2声から始める。強拍に3度や7度が来るメロディなら、ルートを足すだけでコードが聞こえる。
- 内声には、3度か7度のうちメロディにない方を選ぶ。メロディが低い場所では、ロー・インターバル・リミットを守るために内声を省く。
- 同じ弦の上では2つの音を同時に鳴らせない。弦の割り当てを必ず確かめる。
- メロディが伸びている場所では、ベースを歩かせる。メロディを押さえる指を先に決めてから、ベースの運指を考える。
- 最後に音を減らす。音が少ないほど、1つひとつの音が生きる。
