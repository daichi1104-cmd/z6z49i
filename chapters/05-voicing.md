# 第5章　ヴォイシング

## 5.1　ベースで和音を弾くための原則

6弦ベースの①②③弦は、ギターの低い3本の弦とほぼ同じ音域にあります。この音域を使えば、ベースでもコードを弾けます。ピアノやギターのいない編成（ベースとサックスのデュオ、ドラムとのトリオ、ソロ・ベース）では、ベースが和音を受け持つことで、音楽の厚みが大きく変わります。

ただし、ベースで和音を弾くときは、第1章で見た**ロー・インターバル・リミット**との戦いになります。本書では、次の3つの原則でヴォイシングを組み立てます。

1. **ルートと上声部を分ける。** ルートは低い弦で短く弾き、和音の上声部は①②③弦で伸ばす。
2. **上声部の隣り合う2音は、ロー・インターバル・リミットの目安より上に置く。** 3度を含む和音は、下の音を C3 付近より上に置く。
3. **上声部はなるべく動かさない。** コードが変わっても、上声部はできるだけ共通の音を残し、半音か全音で動かす。

この章の和音の譜例は、2段で書きます。上の段（ト音記号）に上声部、下の段（ヘ音記号）にルートを書きます。どちらの段も、実音の1オクターブ上に記譜しています。

## 5.2　ガイドトーン・ライン

第1章の譜例1-4では、Ⅱ-Ⅴ-Ⅰの3度と7度（ガイドトーン）を②①弦で弾きました。この考え方を、もっと長いコード進行に広げます。

ガイドトーンには、はっきりした規則があります。コードが4度進行するとき、**前のコードの7度は、次のコードの3度へ半音か全音で下がり、前のコードの3度は、次のコードの7度にそのまま残る**のです。その結果、2つの声部の上下が、コードごとに「7度が下・3度が上」と「3度が下・7度が上」に交互に入れ替わります。

譜例5-1は、C のキーで4度進行を7つ続けた例です。

```lilypond {#ex5-1 caption="譜例5-1　ガイドトーン・ライン（②①弦）"}
<<
  \new ChordNames \chordmode {
    d1:m7 g:7 c:maj7 f:maj7 b:m7.5- e:7 a:m7 a:m7
  }
  \new PianoStaff <<
    \new Staff {
      \clef treble \time 4/4 \set stringNumberOrientations = #'(up)
      r4 <c'\2 f'\1>2. | r4 <b\2 f'\1>2. | r4 <b\2 e'\1>2. | r4 <a\2 e'\1>2. | \break
      r4 <d'\2 a'\1>2. | r4 <d'\2 gis'\1>2. | r4 <c'\2 g'\1>2. | r4 <c'\2 g'\1>2. \bar "||"
    }
    \new Staff {
      \clef bass \time 4/4 \set stringNumberOrientations = #'(down)
      d4\4 r2. | g,4\5 r2. | c4\4 r2. | f,4\5 r2. |
      b,4\5 r2. | e,4\5 r2. | a,4\5 r2. | a,4\5 r2. \bar "||"
    }
  >>
>>
```

1〜4小節目では、上声部はほとんど動きません。C→B→B→A、F→F→E→E と、半音か全音で下りていくだけです。

5小節目に注目してください。4度進行の規則どおりに続けると、Bm7(♭5) は A2 と D3、E7 は G♯2 と D3 になります。ところが G♯2 と D3 のトライトーンは、下の音が目安（B♭2）を下回るので濁ります。そこで5小節目で上声部の上下を入れ替え、**下の音を1オクターブ上に移して**います（A2 → A3）。上声部が低くなりすぎたら、1オクターブ上に移して仕切り直す。これがガイドトーン・ラインを実際に弾くときのコツです。

## 5.3　4度の和音：弦をまとめて押さえる

ベースの弦は、隣り合う弦がすべて完全4度の関係にあります。したがって、**③②①弦を1本の指でまとめて押さえる（セーハする）と、その形はいつも4度を2つ重ねた和音**になります。ピアノでは手の形を工夫しないと作れない4度堆積の和音が、6弦ベースでは最も簡単な形で手に入ります。

4度の和音は、3度を含まないので、長調とも短調ともつかない開かれた響きがします。モード・ジャズの伴奏や、sus4 コードの響きに向いています。第6章のモード・ジャズは、この響きが中心になります。

譜例5-2は、Dm7（D ドリアン）の上で、③②①弦をまとめて押さえた形を平行に動かす例です。ルートの D2 は⑤弦で弾きます。

```lilypond {#ex5-2 caption="譜例5-2　4度の和音の平行移動（Dドリアン）"}
<<
  \new ChordNames \chordmode { d1:m7 d:m7 d:m7 d:m7 }
  \new PianoStaff <<
    \new Staff {
      \clef treble \time 4/4 \set stringNumberOrientations = #'(up)
      r4 <a\3 d'\2 g'\1>2. | r4 <b\3 e'\2 a'\1>2. |
      r4 <d'\3 g'\2 c''\1>2. | r4 <b\3 e'\2 a'\1>2. \bar "||"
    }
    \new Staff {
      \clef bass \time 4/4 \set stringNumberOrientations = #'(down)
      d4\5 r2. | d4\5 r2. | d4\5 r2. | d4\5 r2. \bar "||"
    }
  >>
>>
```

3つの形の音は、Dm7 の上では次のように聞こえます。

| 小節 | 上声部（下から） | Dm7 に対する度数 |
|---|---|---|
| 1 | A - D - G | 5度、1度、11度 |
| 2 | B - E - A | 13度、9度、5度 |
| 3 | D - G - C | 1度、11度、7度 |

どの音も D ドリアンの中にあるので、ルートが D のまま動かなくても、響きの色だけが移り変わります。一番下の音は、1小節目の A2 が最も低く、完全4度の目安（A2）をちょうど満たしています。これより低い位置でまとめて押さえると、和音が濁り始めます。

## 5.4　アッパー・ストラクチャー・トライアド

**アッパー・ストラクチャー・トライアド**は、コードの上に別の三和音（トライアド）を重ねて、テンションを含む響きを作る方法です。三和音は形が単純なので、テンションの多い複雑なコードでも、少ない音で明確に鳴らせます。

ドミナント7thコード（G7）でよく使う組み合わせを、表にまとめます。

| G7 の上に重ねる三和音 | 三和音の音 | G7 に対する度数 | できるコード |
|---|---|---|---|
| A メジャー | A - C♯ - E | 9, ♯11, 13 | G13(♯11) |
| E♭ メジャー | E♭ - G - B♭ | ♭13, 1, ♯9 | G7(♯9, ♭13) |
| E メジャー | E - G♯ - B | 13, ♭9, 3 | G13(♭9) |
| D♭ メジャー | D♭ - F - A♭ | ♯11, 7, ♭9 | G7(♭9, ♯11) |

トニックやサブドミナントでも、同じ考え方が使えます。Dm7 の上に F メジャーを重ねると Dm7 の3・5・7度、Cmaj7 の上に E マイナーを重ねると Cmaj7 の3・5・7度になります。

譜例5-3は、Ⅱ-Ⅴ-Ⅰの上で三和音をつないだ例です。三和音は③②①弦で弾き、ルートは⑤弦か⑥弦で弾きます。

```lilypond {#ex5-3 caption="譜例5-3　アッパー・ストラクチャー・トライアドのつながり"}
<<
  \new ChordNames \chordmode {
    d1:m7
    \once \override ChordName.text = \markup { "G" \super { "13(" \sharp "11)" } } g1:7
    \once \override ChordName.text = \markup { "G" \super { "7(" \sharp "9," \flat "13)" } } g1:7
    c1:maj7
  }
  \new PianoStaff <<
    \new Staff {
      \clef treble \time 4/4 \set stringNumberOrientations = #'(up)
      r4 <c'\3 f'\2 a'\1>2. | r4 <cis'\3 e'\2 a'\1>2. |
      r4 <bes\3 es'\2 g'\1>2. | r4 <b\3 e'\2 g'\1>2. \bar "|."
    }
    \new Staff {
      \clef bass \time 4/4 \set stringNumberOrientations = #'(down)
      d4\5 r2. | g,4\6 r2. | g,4\6 r2. | c4\5 r2. \bar "|."
    }
  >>
>>
```

上声部の動きを1声ずつ追ってみます。

| 声部 | Dm7（F） | G13(♯11)（A） | G7(♯9,♭13)（E♭） | Cmaj7（Em） |
|---|---|---|---|---|
| 上 | A | A | G | G |
| 中 | F | E | E♭ | E |
| 下 | C | C♯ | B♭ | B |

上の声部は A → A → G → G と、ほとんど動きません。中の声部は F → E → E♭ → E と半音で動き、下の声部も C → C♯ → B♭ → B と半音か短3度で動きます。最後の E♭ → Em では、上の G を残したまま、下の2声が半音ずつ上がって解決します。**三和音そのものは大きく変わっても、上声部の1つひとつは少ししか動かない**。これが、複雑なテンションを含むコード進行を、なめらかに聞かせる仕組みです。

すべての和音で、隣り合う2音はロー・インターバル・リミットの目安より上にあります。たとえば3小節目の B♭2 - E♭3 は完全4度（目安 A2）、E♭3 - G3 は長3度（目安 B♭2）です。

## 5.5　リズムを付けて伴奏する

ここまでの譜例は、和音を全音符に近い長さで伸ばしていました。実際の伴奏（コンピング）では、和音にリズムを付けます。ジャズで最も基本的な伴奏のリズムは、1拍目と2拍目の裏を打つ**チャールストン**です。

譜例5-4は、譜例5-1のガイドトーンにチャールストンのリズムを付けた例です。1拍目でルートを弾き、2拍目の裏で上声部を弾いて伸ばします。

```lilypond {#ex5-4 caption="譜例5-4　チャールストンのリズムで伴奏する"}
<<
  \new ChordNames \chordmode { d1:m7 g:7 c:maj7 c:maj7 }
  \new PianoStaff <<
    \new Staff {
      \clef treble \time 4/4 \set stringNumberOrientations = #'(up)
      r4 r8 <c'\2 f'\1>8~ <c' f'>2 | r4 r8 <b\2 f'\1>8~ <b f'>2 |
      r4 r8 <b\2 e'\1>8~ <b e'>2 | r4 r8 <b\2 e'\1>8~ <b e'>2 \bar "||"
    }
    \new Staff {
      \clef bass \time 4/4 \set stringNumberOrientations = #'(down)
      d4\4 r2. | g,4\5 r2. | c4\4 r2. | c4\4 r2. \bar "||"
    }
  >>
>>
```

8分音符はスウィングで弾きます。ルートと上声部をずらして弾くことで、1人でベースと伴奏の2役を受け持っているように聞かせられます。慣れてきたら、上声部を前の小節の4拍目の裏に食い込ませる（アンティシペーション）など、リズムを変えてみてください。

## 5.6　バンドの中でのヴォイシング

ピアノやギターがいる編成で和音を弾くときは、次の点に気をつけてください。

- **ピアノの左手と同じ音域を避ける。** ピアノの左手のヴォイシングは、おおむね C3〜C4 にあります。①②③弦の和音はこの音域と重なるので、ピアノが弾いているときは、和音ではなく単音のラインに戻るのが基本です。
- **ピアノが休んでいる場面で使う。** ピアニストのソロの最中や、ピアニストが意図的に伴奏を休んでいる場面（ストロール）では、ベースの和音が生きます。
- **テンションはピアノと合わせる。** アッパー・ストラクチャーのように特定のテンションを含む和音は、ピアノが別のテンションを弾くとぶつかります。バンドで合意してから使ってください。

## 5.7　練習課題

1. 譜例5-1のガイドトーン・ラインを、F のキー（Gm7 - C7 - Fmaj7 - B♭maj7 - Em7(♭5) - A7 - Dm7）で作ってください。上声部の下の音が目安を下回ったら、どこで1オクターブ上に移すかを決めます。
2. 譜例5-2の4度の和音を、E♭ ドリアン（ルートは E♭）で作ってください。どの位置でまとめて押さえると E♭ ドリアンの音だけになるかを探します。
3. 5.4節の表の4つの三和音を、G7 の上で③②①弦の和音として弾いてください。それぞれ、隣り合う2音がロー・インターバル・リミットの目安より上にあるかを確かめます。
4. 譜例5-3のつながりを、F のキー（Gm7 - C7 - Fmaj7）に移してください。上の声部ができるだけ動かない三和音の転回形を選びます。
5. 譜例5-4のリズムで、ブルース（F7 - B♭7 - F7 - F7 - B♭7 - B♭7 - F7 - D7 - Gm7 - C7 - F7 - C7）を1コーラス弾いてください。

## 5.8　まとめ

- ベースで和音を弾くときは、ルートを低い弦で短く弾き、上声部を①②③弦で伸ばす。
- 上声部の隣り合う2音は、ロー・インターバル・リミットの目安より上に置く。上声部が低くなりすぎたら、1オクターブ上に移して仕切り直す。
- ガイドトーン（3度と7度）は、4度進行では半音か全音で動き、上下が交互に入れ替わる。
- 隣り合う弦が4度の関係にあるので、③②①弦をまとめて押さえると4度の和音になる。
- アッパー・ストラクチャー・トライアドでは、三和音が大きく変わっても、上声部の1つひとつは少ししか動かないようにつなぐ。
- バンドの中では、ピアノの左手の音域を避け、ピアノが休んでいる場面で和音を使う。
