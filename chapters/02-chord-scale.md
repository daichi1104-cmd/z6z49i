# 第2章　コード・スケール理論を指板に落とす

## 2.1　コード・スケールの考え方

コード・スケール理論は、「このコードの上で使える音はどれか」に答えるための理論です。コードの1つひとつに、それに合うスケールを割り当てます。スケールの7つの音は、次の3種類に分かれます。

- **コード・トーン**：1度、3度、5度、7度。コードそのものの音です。
- **テンション**：9度、11度、13度。コードに重ねても響きを壊さず、色を足す音です。
- **アヴォイド・ノート**：コード・トーンの半音上にあって、長く鳴らすとコードの響きを濁らせる音です。経過音としては使えますが、拍の頭で伸ばすのは避けます。

中級以上の読者なら、ここまでは知っていると思います。この章の目的は、知識を増やすことではありません。**コード・スケールを6弦の1つのポジションの中に収め、コードが変わっても手を動かさずにスケールを切り替えられるようにする**ことです。

まず、本書で使う主なコード・スケールを確認しておきます。

| コード | 主なスケール | テンション | アヴォイド |
|---|---|---|---|
| maj7 | アイオニアン | 9, 13 | 11 |
|  | リディアン | 9, ♯11, 13 | なし |
| m7 | ドリアン | 9, 11, 13 | なし（※） |
|  | エオリアン | 9, 11 | ♭13 |
| m6, m(maj7) | メロディック・マイナー | 9, 11 | なし |
| m7(♭5) | ロクリアン | 11, ♭13 | ♭9 |
|  | ロクリアン♮2 | 9, 11, ♭13 | なし |
| 7 | ミクソリディアン | 9, 13 | 11 |
|  | リディアン♭7 | 9, ♯11, 13 | なし |
|  | オルタード | ♭9, ♯9, ♯11, ♭13 | なし |
| dim7 | ディミニッシュ（全音・半音） | 9, 11, ♭13, 長7度 | なし |

※ドリアンの13度は、トニックのマイナーでは響きが曖昧になるので、使い方に注意が必要です。

## 2.2　3度で積むと、スケールはコードの延長になる

スケールを1度から順に弾くのではなく、**1つおきに**（3度ずつ）並べ直してみます。D ドリアンなら、D-F-A-C-E-G-B-D です。前半の D-F-A-C が Dm7 のコード・トーン、後半の E-G-B が 9度・11度・13度のテンションです。つまりスケールは、**コードを上に伸ばしたもの**として見ることができます。

6弦ベースでは、この3度の積み重ねが1つのポジションに収まります。譜例2-1は、⑥弦の D1 に人差し指を置いた手の位置（以下「Dポジション」）のまま、D1 から D3 まで3度を積んだ例です。

```lilypond {#ex2-1 caption="譜例2-1　Dドリアンを3度で積む（Dポジション）"}
<<
  \new ChordNames \chordmode { d1:m7 d1:m7 }
  \new Staff {
    \clef bass \time 4/4
    d,4\6 f,\6 a,\5 c\4 | e\4 g\3 b\2 d'\2 \bar "|."
  }
  \addlyrics { "1" "3" "5" "7" "9" "11" "13" "1" }
>>
```

弦との対応を見てください。コード・トーンは⑥⑤④弦に、テンションは④③②弦にあります。Dポジションでは、**下の弦でコード、上の弦でテンション**という配置になります。ベースラインを組むときは下の弦でコードの骨格を示し、上の弦に行くほどテンションで色を付けていく、という考え方がそのまま指板の形になります。

3度の間を埋めると、スケールになります。譜例2-2は、同じポジションで D ドリアンを2オクターブ弾く例です。

```lilypond {#ex2-2 caption="譜例2-2　Dドリアン2オクターブ（Dポジション）"}
\new Staff {
  \clef bass \time 4/4
  d,4\6 e,\6 f,\6 g,\5 | a,\5 b,\5 c\4 d\4 |
  e\4 f\3 g\3 a\3 | b\2 c'\2 d'2\2 \bar "|."
}
```

Dポジションは、実音で D1 から G3 まで、半音階のすべての音を1つのポジションで押さえられる範囲です。この章の譜例は、すべてこのポジションの中で弾けるように作ってあります。

## 2.3　コードが変わっても、手は動かさない

コード・スケール理論を実際の演奏で使うときの難しさは、コードが変わるたびにスケールを切り替えなければならないことです。4弦ベースでは、スケールを切り替えるたびにポジションも変わりがちで、頭の切り替えと手の移動が重なります。

6弦ベースなら、ポジションを固定したまま、**指が押さえるフレットの組み合わせだけを変える**ことができます。ここではマイナーのⅡ-Ⅴ-Ⅰ（Dm7(♭5) - G7alt - Cm6）を例に、Dポジションのまま3つのスケールを切り替えます。

| コード | スケール | 音 | 元になるメロディック・マイナー |
|---|---|---|---|
| Dm7(♭5) | ロクリアン♮2 | D E F G A♭ B♭ C | F メロディック・マイナー |
| G7alt | オルタード | G A♭ B♭ B D♭ E♭ F | A♭ メロディック・マイナー |
| Cm6 | メロディック・マイナー | C D E♭ F G A B | C メロディック・マイナー |

3つとも、メロディック・マイナーから作られるスケールです。メロディック・マイナーの運指を1つのポジションで覚えておけば、マイナーのⅡ-Ⅴ-Ⅰは**3つのキーのメロディック・マイナーを順に弾く**ことに置き換えられます。

譜例2-3は、G オルタード・スケールをDポジションで2オクターブ弾く例です。オルタード・スケールは、表記上は♭9（A♭）、♯9（B♭）、3度（B）、♯11（D♭）、♭13（E♭）、♭7（F）と読みます。

```lilypond {#ex2-3 caption="譜例2-3　Gオルタード・スケール2オクターブ（Dポジション）"}
\new Staff {
  \clef bass \time 4/4
  g,4\5 aes,\5 bes,\5 b,\5 | des\4 es\4 f\3 g\3 | \break
  aes\3 bes\2 b\2 des'\2 | es'\1 f'\1 g'2\1 \bar "|."
}
\addlyrics { "1" "♭9" "♯9" "3" "♯11" "♭13" "♭7" "1" "♭9" "♯9" "3" "♯11" "♭13" "♭7" "1" }
```

譜例2-2と同じポジションで、①弦まで使い切っています。D ドリアンとは押さえるフレットがまったく違いますが、手の位置は同じです。

## 2.4　スケールからラインを作る

スケールの音を順に弾くだけでは、ベースラインになりません。ウォーキングでは、次の2つの決まりを守ると、スケールの音がラインとして機能します。

1. **1拍目には、コード・トーン（多くはルートか3度）を置く。**
2. **4拍目には、次の小節の1拍目へ半音か全音で近づく音を置く。**

譜例2-4は、この決まりに従って、2.3節のマイナーのⅡ-Ⅴ-Ⅰをウォーキングにした例です。

```lilypond {#ex2-4 caption="譜例2-4　マイナーⅡ-Ⅴ-Ⅰのウォーキング（Dポジション）"}
<<
  \new ChordNames \chordmode {
    d1:m7.5-
    \once \override ChordName.text = \markup { "G" \super "7alt" } g1:7
    c1:m6 c1:m6
  }
  \new Staff {
    \clef bass \time 4/4
    d4\4 e\4 f\3 aes\3 | g\3 f\3 es\4 des\4 |
    c\4 es\4 g\3 a\3 | c'\2 b\2 a\3 g\3 \bar "||"
  }
>>
```

各小節の流れを見ていきます。

- **1小節目（Dm7(♭5)）**：ルートの D から上行し、4拍目の A♭（♭5度）で G7alt のルート G へ半音上から近づきます。2拍目の E は、ロクリアン♮2 の 9度です。
- **2小節目（G7alt）**：ルートから下行して、F（♭7）、E♭（♭13）、D♭（♯11）とオルタード・スケールの音をたどります。4拍目の D♭ は、次の C へ半音上から解決します。
- **3〜4小節目（Cm6）**：Cm6 のコード・トーン C、E♭、G、A を上行し、4小節目では C メロディック・マイナーの B（長7度）を通って G に下ります。

2小節目のラインは、G から D♭ まで、ちょうどトライトーン（増4度）下りています。D♭ は G7 の裏コードである D♭7 のルートでもあります。オルタードの響きをベースラインで示すには、**♯11（= 裏コードのルート）を4拍目に置いて、半音で解決する**のが最も効果的です。この考え方は第4章のリハーモナイゼーションにつながります。

## 2.5　アヴォイド・ノートの扱い

アヴォイド・ノートは、「弾いてはいけない音」ではありません。**置く場所を選ぶ音**です。

譜例2-5は、Cmaj7 の上でアヴォイド・ノートの F（11度）を使う2つの例です。（a）では F を1拍目に置いているので、コードが Fmaj7 のように聞こえ、ラインがコードとぶつかります。（b）では F を2拍目の経過音として使っているので、E から G への流れの一部として自然に聞こえます。

```lilypond {#ex2-5 caption="譜例2-5　アヴォイド・ノートの位置（Cmaj7）"}
<<
  \new ChordNames \chordmode { c1:maj7 c1:maj7 }
  \new Staff {
    \clef bass \time 4/4
    f4\3^"(a)" e\4 d\4 c\4 \bar "||"
    e4\4^"(b)" f\3 g\3 a\3 \bar "||"
  }
>>
```

アヴォイド・ノートの扱いは、次のようにまとめられます。

- 強拍（1拍目と3拍目）に置かない。
- 置くときは、すぐに半音か全音で隣のコード・トーンへ進む。
- 低域では特に濁りやすいので、経過音でも短く弾く。

## 2.6　ドミナント・コードのスケールの選び方

ドミナント7thコードは、選べるスケールが最も多いコードです。何を基準に選ぶかを、次の表にまとめます。

| ドミナントの状況 | 第一候補のスケール | 特徴のある音 |
|---|---|---|
| 長調のⅠに解決する（G7→C） | ミクソリディアン | 9, 13 |
| 解決しない（ブルースのⅠ7、Ⅳ7、裏コード） | リディアン♭7 | ♯11 |
| 短調のⅠに解決する（G7→Cm） | オルタード | ♭9, ♯9, ♯11, ♭13 |
|  | ハーモニック・マイナー・パーフェクト5th・ビロウ | ♭9, ♭13 |
| 7(♭9, 13) の響きがほしいとき | コンビネーション・オブ・ディミニッシュ | ♭9, ♯9, ♯11, 13 |

ベーシストにとっての実用的な判断は、**解決先が長調か短調か**です。解決先が短調なら、♭13（E♭）や♭9（A♭）を含むスケールを選ぶと、次のトニック・マイナーの3度（E♭）や♭6度（A♭）を先取りする形になり、解決がなめらかになります。

## 2.7　練習課題

1. 譜例2-1のように、Cmaj7（アイオニアン）、G7（ミクソリディアン）、Bm7(♭5)（ロクリアン）を、Dポジションの中で3度に積んでください。それぞれ、コード・トーンとテンションがどの弦に来るかを書き出します。
2. F、A♭、C のメロディック・マイナーを、Dポジションで2オクターブずつ弾いてください。これで 2.3節のマイナーのⅡ-Ⅴ-Ⅰの3つのスケールがすべて揃います。
3. 譜例2-4と同じコード進行で、1拍目と4拍目の決まりを守りながら、自分のラインを4コーラス分作ってください。毎コーラス、2小節目の4拍目には D♭ 以外のアプローチ・ノート（A、E♭ など）を試します。
4. 譜例2-5の（b）のように、アヴォイド・ノートを経過音として含むラインを、G7（ミクソリディアンの11度＝C）と Am7（エオリアンの♭13＝F）で作ってください。

## 2.8　まとめ

- スケールを3度で積むと、前半がコード・トーン、後半がテンションになる。スケールはコードの延長として見られる。
- Dポジション（⑥弦の D1 に人差し指を置く手の位置）は、実音 D1〜G3 を半音階ですべて押さえられる。ポジションを固定したまま、スケールを切り替えられる。
- マイナーのⅡ-Ⅴ-Ⅰのスケールは、3つのキーのメロディック・マイナーに置き換えられる。
- ウォーキングでは、1拍目にコード・トーン、4拍目に次のコードへのアプローチ・ノートを置く。
- アヴォイド・ノートは、強拍を避けて経過音として使う。
