# 第7章　ソロの語法

## 7.1　ベース・ソロは「歌う」ことから

ベース・ソロには、ほかの楽器のソロとは違う条件があります。ベースがソロを弾いている間は、バンドの低音が空になること。そして、ほかの楽器より音が低く、輪郭がぼやけやすいことです。そのため、ジャズのベース・ソロでは伝統的に、次のことが大切にされてきました。

- **伴奏を薄くしてもらう。** ベース・ソロの間、ピアノやドラムは音量と音数を落とします。ベーシスト自身も、伴奏が薄い中で弾いていることを意識します。
- **音を詰め込みすぎない。** 休符を多めにとり、フレーズとフレーズの間に「息つぎ」を入れます。
- **歌えるフレーズを弾く。** 速く弾くことよりも、メロディとして覚えられるフレーズを弾くことが、聴き手の心に残ります。

6弦ベースは、ソロの楽器として大きな利点を持っています。①②弦の高い音域は、テナー・サックスとほぼ同じ高さです。ほかの楽器のソロで使われる語法を、そのままの音域で弾けます。この章では、ジャズのソロの代表的な語法を、6弦ベースの上で整理します。

## 7.2　ビバップ・スケール

8分音符でスケールを下りると、ふつうの7音のスケールでは、小節の途中でコード・トーンが拍の裏にずれてしまいます。**ビバップ・スケール**は、7音のスケールに経過音を1つ足して8音にし、**コード・トーンがいつも拍の頭に来る**ようにしたスケールです。

ドミナント7thコードには、ミクソリディアンに長7度を足した**ドミナント・ビバップ・スケール**を使います。G7 なら、G ミクソリディアン（G A B C D E F）に F♯ を足して、G - F♯ - F - E - D - C - B - A の8音になります。

譜例7-1は、G7 の上でドミナント・ビバップ・スケールを G3 から8分音符で下り、Cmaj7 に解決する例です。

```lilypond {#ex7-1 caption="譜例7-1　ドミナント・ビバップ・スケール（G7 → Cmaj7）"}
<<
  \new ChordNames \chordmode { g1:7 c:maj7 }
  \new Staff {
    \clef bass \time 4/4
    g'8\1 fis'\1 f'\1 e'\1 d'\2 c'\2 b\2 a\3 |
    g4\3 e\4 c2\4 \bar "||"
  }
>>
```

1小節目の拍の頭（1拍目、2拍目、3拍目、4拍目）には、G、F、D、B と、G7 のコード・トーンがすべて並んでいます。経過音の F♯ が、G と F の間を半音でつないでいるためです。2小節目の1拍目の G2 は、Cmaj7 の5度です。

ビバップ・スケールは、**上から下りるときに**使うのが基本です。上行では、経過音を足さなくても、コード・トーンを拍の頭に置きやすいからです。1小節目は、すべて Dポジション（⑥弦の D1 に人差し指を置いた手の位置）で弾けます。

## 7.3　エンクロージャー

**エンクロージャー**は、目標の音を上と下から挟んでから着地する語法です。第3章でアプローチ・ノートの1つの型として紹介しましたが、ソロではビバップの最も重要な語法になります。

典型的な形は、**スケール上で目標の1つ上の音 → 目標の半音下の音 → 目標の音**です。目標には、次のコードの3度を選ぶと、コードが変わった瞬間がはっきり聞こえます。

譜例7-2は、Ⅱ-Ⅴ-Ⅰで、G7 の3度（B）と Cmaj7 の3度（E）をエンクロージャーで狙った例です。

```lilypond {#ex7-2 caption="譜例7-2　エンクロージャーで3度に着地する（Ⅱ-Ⅴ-Ⅰ）"}
<<
  \new ChordNames \chordmode { d1:m7 g:7 c:maj7 }
  \new Staff {
    \clef bass \time 4/4
    d'8\2 c'\2 a\3 f\3 g\3 a\3 c'\2 ais\2 | \break
    b8\2 d'\2 g\3 b\2 d'\2 g'\1 f'\1 dis'\1 |
    e'2\1 r2 \bar "||"
  }
>>
```

- **1小節目の最後**：C3（スケール上で B の1つ上）→ A♯2（B の半音下）→ 2小節目の1拍目の B2。
- **2小節目の最後**：F3（スケール上で E の1つ上）→ D♯3（E の半音下）→ 3小節目の1拍目の E3。

どちらも、コードが変わる瞬間に、新しいコードの3度が鳴ります。エンクロージャーの2音目（半音下の音）はスケールの外の音ですが、すぐに目標へ解決するので、外れた音には聞こえません。この譜例も、すべて Dポジションで弾けます。

## 7.4　アウトサイド：わざと外して、戻る

**アウトサイド**は、コードやモードから意図的に外れた音を弾いて緊張を作り、元に戻って解決する語法です。外れ方にはいろいろありますが、最も分かりやすいのは**サイドステップ**（フレーズをそのまま半音上か半音下にずらす方法）です。

サイドステップでは、**フレーズの形を保ったまま外れる**ことが大切です。形がはっきりしていれば、聴き手は「わざと外している」と分かり、戻ったときに解決を感じます。形が崩れていると、ただの間違いに聞こえます。

6弦ベースでは、**指の形をそのまま保って、手の位置ごと半音ずらす**だけで、サイドステップができます。譜例7-3は、Dm7（D ドリアン）の上で、D マイナー・ペンタトニックのフレーズを1小節だけ半音上にずらした例です。

```lilypond {#ex7-3 caption="譜例7-3　サイドステップ（Dm7 の上で半音上にずらす）"}
<<
  \new ChordNames \chordmode { d1:m7 d:m7 d:m7 d:m7 }
  \new Staff {
    \clef bass \time 4/4
    d8\4^"in" f\3 g\3 a\3 c'\2 a\3 g\3 f\3 |
    es8\4^"out" ges\3 aes\3 bes\3 des'\2 bes\3 aes\3 ges\3 |
    a8\3^"in" g\3 f\3 d\4 f\3 g\3 a\3 c'\2 |
    d'2\2 r2 \bar "||"
  }
>>
```

- **1小節目（イン）**：D マイナー・ペンタトニック（D F G A C）のフレーズです。
- **2小節目（アウト）**：同じフレーズを半音上にずらし、E♭ マイナー・ペンタトニック（E♭ G♭ A♭ B♭ D♭）にしています。Dm7 の上では、ほとんどの音がぶつかります。
- **3〜4小節目（イン）**：元のペンタトニックに戻り、4小節目でルートの D3 に着地します。

アウトサイドを使うときの決まりは3つです。

1. **短く外れる。** 1〜2小節が目安です。
2. **形を保って外れる。** 同じ形のまま、平行にずらす。
3. **必ず戻る。** 戻ったら、コード・トーン（できればルートか3度）に着地する。

## 7.5　モチーフを育てる

上級のソロと中級のソロの最も大きな違いは、**フレーズとフレーズの間につながりがあるか**です。上級の奏者は、短いフレーズ（**モチーフ**）を1つ決め、それを繰り返したり、形を変えたりしながらソロを組み立てます。聴き手は、モチーフが変化していく様子を追いかけることで、ソロを1つの物語として聞きます。

モチーフの変化のさせ方には、次のようなものがあります。

| 方法 | やり方 |
|---|---|
| 反復 | 同じモチーフをそのまま繰り返す |
| 音の調整 | リズムを保ったまま、新しいコードに合わせて音だけを変える |
| 移動（シークエンス） | モチーフ全体を、スケールに沿って上や下に移す |
| 伸縮 | 音を足したり、最後の音を長く伸ばしたりする |
| リズムのずらし | モチーフの始まりを、半拍や1拍ずらす |

譜例7-4は、3音のモチーフを、Ⅱ-Ⅴ-Ⅰの上で**音の調整**と**伸縮**で育てた例です。

```lilypond {#ex7-4 caption="譜例7-4　モチーフの展開（Ⅱ-Ⅴ-Ⅰ）"}
<<
  \new ChordNames \chordmode { d1:m7 g:7 c:maj7 c:maj7 }
  \new Staff {
    \clef bass \time 4/4
    r8 a\3 c'\2 d'\2~ d'4 r4 |
    r8 b\2 d'\2 f'\1~ f'4 r4 |
    r8 b\2 d'\2 e'\1~ e'2 |
    R1 \bar "||"
  }
>>
```

3つの小節は、すべて同じリズム（半拍休んで、8分音符3つ、最後の音を伸ばす）です。音はコードに合わせて変えています。

- **1小節目（Dm7）**：A - C - D。5度、7度、ルート。
- **2小節目（G7）**：B - D - F。3度、5度、7度。最後の F は、Dm7 のときの D から短3度上がっています。
- **3小節目（Cmaj7）**：B - D - E。7度、9度、3度。最後の E を長く伸ばして、フレーズを締めくくります。

4小節目は、まるごと休符です。モチーフを3回聞かせたあとの休符は、聴き手に「ここで1つの話が終わった」と伝えます。**休符もソロの一部**です。

## 7.6　ソロ全体の組み立て

1コーラス、あるいは数コーラスのソロを、どう組み立てるか。第3章で見た「ラインを1つの山として設計する」考え方は、ソロにもそのまま使えます。

| 段階 | 音域 | 音の密度 | 使う語法 |
|---|---|---|---|
| 始まり | 中域〜高域の下のほう | 少ない。休符が多い | モチーフの提示、コード・トーン中心 |
| 展開 | 高域 | 少しずつ増える | モチーフの展開、エンクロージャー |
| 山場 | 高域の上のほう | 多い。8分音符が続く | ビバップ・スケール、アウトサイド |
| 終わり | 中域へ戻る | 少なくなる | モチーフに戻る、ルートか3度に着地 |

ポイントは2つです。

- **最初から全部を出さない。** 最も高い音、最も速いフレーズ、アウトサイドは、山場のためにとっておきます。
- **最初のモチーフで終わる。** ソロの最後に、始まりのモチーフをもう一度弾くと、ソロ全体が1つの形にまとまります。

## 7.7　練習課題

1. 譜例7-1のドミナント・ビバップ・スケールを、C7（C - B - B♭ - A - G - F - E - D）と F7 で作ってください。1小節の拍の頭がすべてコード・トーンになることを確かめます。
2. 譜例7-2と同じく、エンクロージャーで3度に着地するⅡ-Ⅴ-Ⅰのフレーズを、F のキー（Gm7 - C7 - Fmaj7）で作ってください。
3. 譜例7-3のサイドステップを、半音下にずらす形でも作ってください。上にずらしたときと響きがどう違うかを比べます。
4. 好きな3音のモチーフを1つ決め、7.5節の表の5つの方法をすべて使って、8小節のソロを作ってください。
5. 手持ちのスタンダード曲で1コーラスのソロを作り、7.6節の表のどの段階がどこにあたるかを書き込んでください。

## 7.8　まとめ

- ベース・ソロでは、音を詰め込みすぎず、歌えるフレーズを弾く。6弦ベースの高い音域は、ほかの楽器の語法をそのまま使える。
- ビバップ・スケールは経過音を1つ足して、8分音符で下りたときにコード・トーンが拍の頭に来るようにしたスケール。
- エンクロージャーは、スケール上の1つ上の音と半音下の音で目標を挟む。目標は次のコードの3度にすると効果的。
- アウトサイドは、形を保ったまま短く外れ、必ず戻ってコード・トーンに着地する。6弦ベースでは、指の形を保って手の位置ごと半音ずらせばよい。
- モチーフを決め、反復、音の調整、移動、伸縮、リズムのずらしで育てる。休符もソロの一部。
- ソロ全体を1つの山として設計し、最初のモチーフで終わる。
