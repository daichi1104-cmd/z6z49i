# 第4章　リハーモナイゼーション

## 4.1　ベーシストは1人でもコードを変えられる

リハーモナイゼーション（リハモ）とは、曲のメロディはそのままに、コード進行を別のものに置き換えることです。ピアニストやアレンジャーのための技術だと思われがちですが、実はベーシストが最も強い影響力を持っています。**和音の響きは、いちばん低い音で決まる**からです。

ピアノが G7 を弾いていても、ベースが D♭ を弾けば、バンド全体は D♭7 のように聞こえます。つまりベーシストは、**ベースラインだけでリハモをほのめかせる**立場にいます。これは大きな武器であると同時に、扱いを誤るとバンド全体の響きを壊す危険でもあります。

この章では、ジャズで最もよく使われるリハモの手法を、ベースラインの観点から整理します。

- 裏コード（トライトーン代理）
- 裏のツー・ファイブ
- バックドア・ドミナント
- セカンダリー・ドミナントの連鎖
- コルトレーン・チェンジ

## 4.2　裏コード：ルートが半音で下りる

G7 の3度（B）と7度（F）は、トライトーン（増4度）の関係にあります。この2音を共有するもう1つのドミナント7thコードが D♭7 です（D♭7 の3度は F、7度は C♭＝B）。G7 と D♭7 はルートがトライトーン離れているので、互いを**裏コード**と呼びます。

| コード | ルート | 3度 | 7度 |
|---|---|---|---|
| G7 | G | B | F |
| D♭7 | D♭ | F | C♭（＝B） |

ベースにとって裏コードの最大の効果は、**ルートの動きが変わる**ことです。Dm7 - G7 - Cmaj7 のルートは D → G → C と4度ずつ跳躍しますが、G7 を D♭7 に置き換えると、D → D♭ → C と半音で下りるラインになります。

```lilypond {#ex4-1 caption="譜例4-1　裏コードを使ったⅡ-Ⅴ-Ⅰ（Dm7 - D♭7 - Cmaj7）"}
<<
  \new ChordNames \chordmode { d1:m7 des:7 c:maj7 c:maj7 }
  \new Staff {
    \clef bass \time 4/4
    d4\4 f\3 e\3 d\4 | des\4 f\3 aes,\5 b,\4 |
    c\4 e\3 g\3 b\2 | c'\2 b\2 a\3 g\3 \bar "||"
  }
>>
```

各小節の1拍目は D2 → D♭2 → C2 と半音で下りています。そのうえで、各小節の4拍目も次の1拍目へ半音で近づいています（1小節目の D2 → D♭2、2小節目の B1 → C2）。2小節目の4拍目の B1 は D♭7 の7度（C♭）で、同時に G7 の3度でもあります。**裏コードを弾きながら、元のコードの3度を通って解決している**わけです。

## 4.3　裏のツー・ファイブ

裏コードの前に、そのツー（Ⅱm7）を置くこともできます。D♭7 のツーは A♭m7 です。元の Dm7 - G7 - Cmaj7 のうち、G7 の小節を A♭m7 - D♭7 に分割すると、ルートは D → A♭ → D♭ → C と動きます。

```lilypond {#ex4-2 caption="譜例4-2　裏のツー・ファイブ（Dm7 - A♭m7 D♭7 - Cmaj7）"}
<<
  \new ChordNames \chordmode { d1:m7 aes2:m7 des:7 c1:maj7 c:maj7 }
  \new Staff {
    \clef bass \time 4/4
    d4\4 c\4 bes,\4 a,\5 | aes,\5 c\4 des\4 b,\4 |
    c\4 e\3 g\3 b\2 | c'\2 g\3 e\3 c\4 \bar "||"
  }
>>
```

1小節目は D2 から音階で下り、4拍目の A1 から半音下の A♭1 へ着地します。2小節目の A♭m7 では、2拍目の C2 から D♭2 へ半音で上がり、4拍目の B1 から C2 へ半音で上がります。

D → A♭ はトライトーンの跳躍です。ピアニストが元の Dm7 - G7 を弾いている場合でも、ベースが2小節目で A♭ を弾くと、強い緊張が生まれます。裏のツー・ファイブは、**バンドで事前に合わせておく**か、ソロの伴奏の最後のコーラスなど、ピアニストが反応できる場面で使ってください。

## 4.4　バックドア・ドミナント

**バックドア・ドミナント**は、Ⅴ7 の代わりに♭Ⅶ7 を使って Ⅰ に解決する進行です。C のキーなら、G7 の代わりに B♭7 を使います。さらに、その前に B♭7 のツーである Fm7 を置くと、Fm7 - B♭7 - Cmaj7 という進行になります。Fm7 は C メジャーのⅣ度をマイナーにしたコード（サブドミナント・マイナー）なので、ブルージーで柔らかい解決になります。

```lilypond {#ex4-3 caption="譜例4-3　バックドア・ドミナント（Fm7 - B♭7 - Cmaj7）"}
<<
  \new ChordNames \chordmode { f1:m7 bes:7 c:maj7 c:maj7 }
  \new Staff {
    \clef bass \time 4/4
    f,4\6 g,\5 aes,\5 a,\5 | bes,\5 d\4 f\3 des\4 |
    c\4 e\3 g\3 b\2 | c,1\6 \bar "|."
  }
>>
```

1小節目は F1 から半音階で上がり、B♭1 に着地します。2小節目の4拍目の D♭2 は B♭7 の♯9度で、C2 へ半音上から解決します。最後の小節では、トニックを⑥弦の C1 まで落としています。バックドア・ドミナントは**曲のエンディング**でよく使われる進行なので、第3章で見た「Low B はエンディングのためにとっておく」と相性がよい場面です。

## 4.5　セカンダリー・ドミナントと裏コードの連鎖

どのダイアトニック・コードの前にも、そのコードへのドミナント（**セカンダリー・ドミナント**）を置くことができます。Cmaj7 - Dm7 - G7 - Cmaj7 なら、Dm7 の前に A7 を置いて Cmaj7 - A7 - Dm7 - G7 - Cmaj7 とします。

ここで A7 と G7 を、それぞれの裏コード（E♭7 と D♭7）に置き換えると、ルートは C → E♭ → D → D♭ → C となり、1小節目の E♭ から先が**半音ずつ下りる**ラインになります。

```lilypond {#ex4-4 caption="譜例4-4　裏コードの連鎖（Cmaj7 E♭7 - Dm7 D♭7 - Cmaj7）"}
<<
  \new ChordNames \chordmode { c2:maj7 es:7 d:m7 des:7 c1:maj7 }
  \new Staff {
    \clef bass \time 4/4
    c4\4 d\4 es\4 des\4 | d\4 a,\5 des\4 b,\4 | c\4 e\3 g\3 b\2 \bar "||"
  }
>>
```

2拍ごとにコードが変わるので、第3章の「ルート＋アプローチ」を繰り返す形になります。1小節目の4拍目の D♭2 は E♭7 の7度で、次の D2 へ半音下から近づきます。2小節目の4拍目の B1 は、譜例4-1と同じく D♭7 の7度です。

このように、裏コードを連ねると、ベースのルートが半音階で下りていきます。**半音で下りるベースラインが聞こえたら、裏コードの連鎖を疑う**と、耳でのコード判別にも役立ちます。

## 4.6　コルトレーン・チェンジ

**コルトレーン・チェンジ**は、トニックを長3度ずつ3つに分けて回る進行です。C のキーのⅡ-Ⅴ-Ⅰ（Dm7 - G7 - Cmaj7）に当てはめると、次のようになります。

| 小節 | 1〜2拍目 | 3〜4拍目 |
|---|---|---|
| 1 | Dm7 | E♭7（A♭ へのドミナント） |
| 2 | A♭maj7 | B7（E へのドミナント） |
| 3 | Emaj7 | G7（C へのドミナント） |
| 4 | Cmaj7 | |

トニックが C → A♭ → E → C と長3度ずつ下がり、それぞれの前にドミナントが付いています。ルートの動きは大きく、4弦ベースでは手の移動が忙しくなる進行です。

6弦ベースなら、この進行全体を**Dポジション（⑥弦の D1 に人差し指を置いた手の位置）のまま**弾けます。

```lilypond {#ex4-5 caption="譜例4-5　コルトレーン・チェンジのウォーキング（Dポジション）"}
<<
  \new ChordNames \chordmode {
    d2:m7 es:7 as:maj7 b:7 e:maj7 g:7 c1:maj7
  }
  \new Staff {
    \clef bass \time 4/4
    d4\4 f\3 es\4 g\3 | aes\3 c'\2 b\2 dis\4 |
    e\4 fis\3 g\3 b,\5 | c1\4 \bar "||"
  }
>>
```

このラインには、はっきりした規則があります。**ドミナントの2拍目（小節の4拍目）には、そのドミナントの3度を置いている**のです。

- E♭7 の3度 G2 → A♭2 へ半音で上がる
- B7 の3度 D♯2 → E2 へ半音で上がる
- G7 の3度 B1 → C2 へ半音で上がる

ドミナントの3度は、解決先のルートの半音下にある**導音**です。ルートが大きく跳ぶ進行でも、ドミナントの3度を4拍目に置けば、すべての解決が半音の動きになります。コルトレーン・チェンジのような難しい進行ほど、この規則が効きます。

## 4.7　メロディとの衝突を確かめる

リハモで最も注意すべきなのは、**メロディの音が新しいコードに合っているか**です。メロディの音は、新しいコードのコード・トーンかテンションでなければなりません。

たとえば、メロディが B を伸ばしている小節で G7 を D♭7 に置き換える場合を考えます。B は D♭7 の7度（C♭）なので、問題なく合います。一方、メロディが D を伸ばしている場合、D は D♭7 の♭9度になり、強い緊張が生まれます。これを狙った効果として使うのか、避けるのかを判断する必要があります。

ベーシストが1人でリハモをほのめかすときは、次の手順で確かめてください。

1. その小節のメロディの音を確かめる。
2. 置き換えたいコードの上で、メロディの音が何度になるかを数える。
3. コード・トーンかテンションなら使ってよい。アヴォイド・ノートや♭9度になる場合は、バンドで合意してから使う。

## 4.8　練習課題

1. 譜例4-1を、F のキー（Gm7 - G♭7 - Fmaj7）と B♭ のキー（Cm7 - B7 - B♭maj7）に移してください。各小節の1拍目が半音で下りることを確かめます。
2. 譜例4-3のバックドア・ドミナントを使って、F のキーのエンディング（B♭m7 - E♭7 - Fmaj7）を作ってください。最後のトニックを、どの弦のどの音で鳴らすかを決めます。
3. Cmaj7 - A7 - Dm7 - G7 を2回繰り返す8小節で、1回目は元のコード、2回目は裏コードの連鎖（譜例4-4）にしたラインを作ってください。
4. 譜例4-5のコルトレーン・チェンジを、手の位置を変えずに4コーラス分弾いてください。毎コーラス、ドミナントの2拍目（小節の4拍目）には3度を置き、それ以外の音は自由に変えます。
5. 手持ちのスタンダード曲を1つ選び、G7 → C のようなドミナントの解決を3か所探してください。それぞれ裏コードに置き換えたときに、メロディの音が何度になるかを書き出します。

## 4.9　まとめ

- 和音の響きはいちばん低い音で決まる。ベーシストはベースラインだけでリハモをほのめかせる。
- 裏コードはルートがトライトーン離れたドミナントで、3度と7度を共有する。使うとルートが半音で下りる。
- 裏のツー・ファイブ、バックドア・ドミナント、セカンダリー・ドミナントの連鎖は、ベースのルートの動きとして覚える。
- コルトレーン・チェンジでも、ドミナントの3度を置けば、解決はすべて半音の動きになる。6弦ベースなら1つの手の位置のまま弾ける。
- リハモをするときは、メロディの音が新しいコードの上で何度になるかを必ず確かめる。
