## 決めたこと・注意すること
- ユーザーはスマホのみ（Roblox Studio なし）。アップロードは必ずここから API で行う。
- APIキーはクラウド環境「roblox-obby」に保存済み（apis.roblox.com 宛てに自動で付く）。新しい会話もこの環境で始めること。キーには universe-places の Write 権限だけがあり、ゲームの名前や公開範囲は API で変えられない。
- 必要なツール：rojo（`cargo install rojo --locked`）。動作確認用に lune、整形用に stylua（Luau 機能付き）を使った。新しいマシンでは入れ直しが要る。
- github.com からのダウンロードは通信が遮断されるため、ツールは cargo で入れる。

## 記録の要点（5行以内）
- スマホのみのユーザー向けに、Rojo でビルドして Open Cloud の place publish API でアップロードする流れを作った。
- 罠：APIキーのIP許可に `0.0.0.0/` と入力して無効になり 403 "Scope not authorized" が出た。`0.0.0.0/0` で解決。
- 罠：非公開ゲームはプロフィールの「作品」に出ない。games/<プレイスID> のリンクから起動する。
- lune で CourseBuilder を動かすと、プロパティ名の誤りと足場の間隔を Roblox なしで確かめられる。
