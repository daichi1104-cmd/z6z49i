## 決めたこと・注意すること
- 他社キャラクターの名前や見た目は使わず、オリジナルにする。
- 道とベースの床は平らな見えない部品（y = 0）のまま。見た目だけ地形にした（敵の動きを変えないため）。雲の上のゾーンだけ、床の部品が見える。
- 道の中の飾りは `Scenery.prop` で一度ためておき、地形を作ったあとに置く。
- はじめの仲間にはレア度がない（rarity = 0）ので、レア度の飾りはつけない。
- 動作確認は lune で行う。lune には Random・RaycastParams・地形の機能がないので、テストでは偽物を作る。部品は CFrame で置く（lune は Position を計算しない）。見た目の確認は、部品を JSON に書き出して three.js で描き、Playwright で画像にする。テスト用のスクリプトは消えるので、書き直しが要る。

## 記録の要点（5行以内）
- 図鑑は2Dの部品（Frame と UICorner）で絵を描き、持っていないドラゴンは真っ黒な影にした。3Dを100匹並べると重いので避けた。
- レア度の飾りは「角の数・とげ・胸の宝石・光る模様・光の輪」を段階的に足した。部品は最大でも+33個。
- 風景は Terrain の FillBlock と FillBall（球を重ねて山にする）で作り、床は見えない部品のまま残した。
- 罠：lune には Random も地形もない。変数名のかぶり（rarity）で★4以上がエラーになるところだった。
