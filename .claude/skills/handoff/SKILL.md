# 引き継ぎメモ

1. 次の形で、引き継ぎメモを `引き継ぎ/YYYY-MM-DD_HHMM_<作業名>.md`（プロジェクトのフォルダからの相対パス）に書く。フォルダがなければ作る。全体で A4 1枚以内。経緯の説明やログの貼り付けは入れない。パスワード・APIキー・顧客の個人情報は書かない。

   ```
   ## 今の状態
   （何が終わって、何が終わっていないか）
   ## 次にやること
   ## 関係するファイルの場所
   ## 決めたこと・注意すること
   ## 記録の要点（5行以内）
   （何をしたか、罠、決めたこと。Obsidian に残す分）
   ```

2. 記録の要点があり、obsidian-recorder エージェントが使える場合は、メモのパスを渡して記録を頼む。使えない場合は記録を書かず、要点はメモに残っているとユーザーに伝える。
3. ユーザーに、次の1行を新しい会話に貼るよう伝える。
   `<メモのパス> の続きをします。メモに書いたファイルだけを読んでください。`
